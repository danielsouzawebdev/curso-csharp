Interfaces Windows Forms com C#

Chegou a hora de criar programas com janelas, botões, caixas de texto e tabelas, como os aplicativos que você usa todos os dias. Este módulo ensina o Windows Forms do zero: o designer do Visual Studio, os controles, os eventos, o layout, a validação, a ligação com dados, vários formulários e a publicação do aplicativo, com 10 projetos passo a passo e código comentado linha a linha. O módulo é independente, mas pressupõe noções de classes em C# (veja os módulos 1 e 2).

Objetivos de aprendizagem

  • Explicar a programação orientada a eventos e o ciclo de um aplicativo Windows Forms.
  • Criar interfaces no designer: formulários, controles, propriedades, layout e ordem de tabulação.
  • Programar eventos (Click, TextChanged, KeyPress, FormClosing, Paint, Tick e outros).
  • Validar dados com ErrorProvider, controles apropriados e tratamento de exceções.
  • Exibir coleções com DataGridView, ListBox, ListView e ComboBox.
  • Trabalhar com vários formulários, caixas de diálogo de arquivo, menus e temporizadores.
  • Manter a interface responsiva com async/await.
  • Separar a interface das regras de negócio, depurar eventos e publicar o aplicativo.

Foco do módulo

Núcleo obrigatório
  • Entender programação orientada a eventos e o ciclo de um formulário.
  • Usar controles, propriedades, eventos e validação.
  • Separar lógica de negócio da interface sempre que possível.
  • Exibir coleções em controles como DataGridView e navegar entre formulários.
Aprofundamento
  • async/await para operações demoradas, publicação e distribuição.
  • GDI+, Timer e projetos complementares para ampliar repertório.
✅ Critério de conclusãoVocê concluiu o módulo quando consegue construir uma aplicação Windows Forms com entrada, validação, processamento, feedback ao usuário e organização mínima entre interface e lógica.
🔗 Conexão com a trilhaOs Módulos 4, 5 e 6 aprofundam três dimensões diferentes da mesma aplicação: experiência do usuário, persistência e qualidade do código.
