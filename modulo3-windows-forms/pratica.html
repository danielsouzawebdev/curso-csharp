Prática guiada · 10 projetos e 4 laboratórios

🧭 Como executar esta práticaDigite o código, execute a cada etapa e compare o comportamento com o resultado descrito. Se houver erro, leia a mensagem antes de alterar o código e use o depurador quando indicado.

Em cada projeto: (1) crie o formulário e configure os controles conforme a tabela (Name primeiro!), (2) defina a ordem de Tab, (3) digite o código lendo os comentários, (4) execute e faça os testes sugeridos, (5) responda às perguntas e tente os desafios. Códigos para .NET 6 ou superior com Nullable ativado (padrão dos modelos atuais).

💡 Os manipuladores de evento têm a forma (object sender, EventArgs e). Nos modelos recentes o Visual Studio pode gerar object? sender: as duas formas funcionam. Se o evento não for criado automaticamente, selecione o controle → ícone ⚡ → clique duplo no evento.

Prepare a solução e conheça o projeto

  1. Crie uma solução Modulo3 e, para cada projeto, adicione um Aplicativo do Windows Forms (C#, .NET LTS): P01Pessoa, P02Imc... .
  2. Em cada um, renomeie Form1 para o nome do formulário (FrmCadastroPessoa, etc.) com clique direito → Renomear e confirme a atualização das referências.
  3. Abra Program.cs e confira que Application.Run(new SeuFormulario()) usa o nome novo.
  4. Para escolher qual executa: clique direito no projeto → Definir como Projeto de Inicialização.
  5. As classes de cada projeto ficam em arquivos próprios (Adicionar → Classe); mantenha o namespace que o Visual Studio colocar.
  6. Faça um commit ao final de cada projeto.
💡 O código mostrado é o seu código (FrmX.cs, tecla F7) e as classes de apoio. O código do designer (FrmX.Designer.cs) é gerado pelo Visual Studio a partir das tabelas de controles, e você não digita.

// ---------- Pessoa.cs ----------
public class Pessoa
{
    public string Nome { get; }                          // só leitura: definido no construtor
    public int Idade { get; }

    public Pessoa(string nome, int idade)                // CONSTRUTOR: valida antes de criar o objeto
    {
        if (string.IsNullOrWhiteSpace(nome))
            throw new ArgumentException("Informe o nome.");
        if (idade < 0 || idade > 130)
            throw new ArgumentException("A idade deve estar entre 0 e 130.");

        Nome = nome.Trim();                              // guarda sem espaços nas pontas
        Idade = idade;
    }

    public bool EhMaiorDeIdade() => Idade >= 18;
    public string Apresentar() => $"Olá, eu sou {Nome} e tenho {Idade} anos.";
}

// ---------- FrmCadastroPessoa.cs (dentro da classe do formulário) ----------
private void btnCadastrar_Click(object sender, EventArgs e)      // roda quando o botão é clicado (ou Enter)
{
    if (!int.TryParse(txtIdade.Text, out int idade))             // texto -> número, sem quebrar
    {
        MessageBox.Show("Digite a idade usando apenas números.", "Atenção",
            MessageBoxButtons.OK, MessageBoxIcon.Warning);       // título, botões e ícone
        txtIdade.Focus();                                        // leva o cursor ao campo com problema
        return;                                                  // sai do método: não continua
    }

    try
    {
        var pessoa = new Pessoa(txtNome.Text, idade);            // a CLASSE valida as regras

    }
    catch (ArgumentException ex)                                 // a classe recusou os dados
    {
        MessageBox.Show(ex.Message, "Dados inválidos", MessageBoxButtons.OK, MessageBoxIcon.Warning);
    }
}

// ---------- Paciente.cs ----------
public class Paciente
{
    public double Peso { get; }                          // em quilos
    public double Altura { get; }                        // em metros

    public Paciente(double peso, double altura)
    {
        if (peso <= 0 || peso > 500) throw new ArgumentException("O peso deve estar entre 0 e 500 kg.");
        if (altura < 0.3 || altura > 2.8) throw new ArgumentException("A altura deve estar entre 0,3 e 2,8 m.");
        Peso = peso;
        Altura = altura;
    }

    public double Imc => Peso / (Altura * Altura);       // propriedade calculada

    public string Classificacao => Imc switch            // switch expression com intervalos (C# 9)
    {
        < 18.5 => "Abaixo do peso",
        < 25   => "Peso normal",                         // só chega aqui se for >= 18,5
        < 30   => "Sobrepeso",
        _      => "Obesidade"                            // _ = todo o resto
    };
}

// ---------- FrmImc.cs ----------
private readonly ErrorProvider erros = new();            // mostra um ícone de erro ao lado do controle

private void btnCalcular_Click(object sender, EventArgs e)
{
    erros.Clear();                                       // apaga os avisos da tentativa anterior

    bool okPeso = double.TryParse(txtPeso.Text, out double peso);
    bool okAltura = double.TryParse(txtAltura.Text, out double altura);

    if (!okPeso) erros.SetError(txtPeso, "Informe o peso em kg. Ex.: 70,5");          // ícone + mensagem no campo
    if (!okAltura) erros.SetError(txtAltura, "Informe a altura em metros. Ex.: 1,75");
    if (!okPeso || !okAltura)                            // se algum falhou, para aqui
    {
        (okPeso ? txtAltura : txtPeso).Focus();          // foco no primeiro campo com erro
        return;
    }

    try
    {
        var paciente = new Paciente(peso, altura);       // a classe valida as faixas
        lblImc.Text = paciente.Imc.ToString("F1");       // 1 casa decimal
        lblClassificacao.Text = paciente.Classificacao;
        lblClassificacao.ForeColor = paciente.Classificacao switch   // cor conforme o resultado
        {
            "Peso normal" => Color.SeaGreen,
            "Abaixo do peso" => Color.DarkOrange,
            _ => Color.Firebrick
        };
    }
    catch (ArgumentException ex)
    {
        MessageBox.Show(ex.Message, "Valor fora da faixa", MessageBoxButtons.OK, MessageBoxIcon.Warning);
    }
}

// ---------- Conversor.cs ----------
public static class Conversor                            // static: funções utilitárias, sem estado
{
    public static double CelsiusParaFahrenheit(double c) => c * 9 / 5 + 32;
    public static double CelsiusParaKelvin(double c) => c + 273.15;
    public static double FahrenheitParaCelsius(double f) => (f - 32) * 5 / 9;
}

// ---------- FrmTemperatura.cs ----------
public FrmTemperatura()
{
    InitializeComponent();
    // UM método para VÁRIOS eventos: sempre que o texto OU a opção mudar, refaz a conversão
    txtValor.TextChanged += ValorOuModoAlterado;
    rdoCF.CheckedChanged += ValorOuModoAlterado;
    rdoCK.CheckedChanged += ValorOuModoAlterado;
    rdoFC.CheckedChanged += ValorOuModoAlterado;
}

private void ValorOuModoAlterado(object? sender, EventArgs e)    // object? : sender pode ser nulo (assinatura padrão atual)
{
    AtualizarResultado();                                // toda a lógica fica em um único lugar
}

private void AtualizarResultado()
{
    if (!double.TryParse(txtValor.Text, out double valor))       // vazio ou inválido
    {
        lblResultado.Text = "—";
        return;
    }

    double resultado;
    string unidade;
    if (rdoCF.Checked)                                   // Checked = true na opção selecionada
    {
        resultado = Conversor.CelsiusParaFahrenheit(valor);
        unidade = "°F";
    }
    else if (rdoCK.Checked)
    {
        resultado = Conversor.CelsiusParaKelvin(valor);
        unidade = "K";
    }
    else
    {
        resultado = Conversor.FahrenheitParaCelsius(valor);
        unidade = "°C";
    }
    lblResultado.Text = $"{resultado:F2} {unidade}";
}

// Evento KeyPress do txtValor (ícone ⚡ > KeyPress): impede teclas inválidas ANTES de aparecerem
private void txtValor_KeyPress(object sender, KeyPressEventArgs e)
{
    char tecla = e.KeyChar;                              // a tecla pressionada
    bool ehDigito = char.IsDigit(tecla);                 // 0 a 9
    bool ehControle = char.IsControl(tecla);             // Backspace, Delete, Enter...
    bool virgulaValida = tecla == ',' && !txtValor.Text.Contains(',');   // uma vírgula só
    bool sinalValido = tecla == '-' && txtValor.SelectionStart == 0 && !txtValor.Text.Contains('-');   // sinal só no início

    if (!(ehDigito || ehControle || virgulaValida || sinalValido))
    {
        e.Handled = true;                                // "já tratei": a tecla é descartada
    }
}

// ---------- Tarefa.cs ----------
public class Tarefa
{
    public string Descricao { get; }
    public bool Concluida { get; private set; }          // só a classe altera

    public Tarefa(string descricao)
    {
        if (string.IsNullOrWhiteSpace(descricao))
            throw new ArgumentException("Descreva a tarefa.");
        Descricao = descricao.Trim();
    }

    public void AlternarConclusao() => Concluida = !Concluida;   // ! inverte true/false

    public override string ToString()                    // o ListBox exibe o resultado do ToString()
        => (Concluida ? "[X] " : "[  ] ") + Descricao;
}

// ---------- FrmTarefas.cs ----------
private readonly List<Tarefa> tarefas = new();           // os DADOS ficam na lista; o ListBox só EXIBE

private void btnAdicionar_Click(object sender, EventArgs e)
{
    try
    {
        tarefas.Add(new Tarefa(txtTarefa.Text));         // a classe valida
        txtTarefa.Clear();
        txtTarefa.Focus();                               // pronto para a próxima tarefa
        tslStatus.Text = "Tarefa adicionada.";
        AtualizarLista();
    }
    catch (ArgumentException ex)
    {
        tslStatus.Text = ex.Message;                     // feedback sem janela: não interrompe o usuário
    }
}

private void lstTarefas_DoubleClick(object sender, EventArgs e)   // duplo clique na lista
{
    if (lstTarefas.SelectedItem is Tarefa tarefa)        // is: confere o tipo e já cria a variável
    {
        tarefa.AlternarConclusao();                      // muda o objeto
        AtualizarLista(lstTarefas.SelectedIndex);        // redesenha mantendo a seleção
    }
}

private void lstTarefas_KeyDown(object sender, KeyEventArgs e)    // tecla pressionada com a lista em foco
{
    if (e.KeyCode == Keys.Delete)                        // tecla Delete
    {
        RemoverSelecionada();
    }
}

private void btnRemover_Click(object sender, EventArgs e) => RemoverSelecionada();

private void RemoverSelecionada()                        // reaproveitado por botão E tecla (sem repetir código)
{
    if (lstTarefas.SelectedItem is not Tarefa tarefa)    // nada selecionado
    {
        tslStatus.Text = "Selecione uma tarefa.";
        return;
    }
    int indice = lstTarefas.SelectedIndex;
    tarefas.Remove(tarefa);
    AtualizarLista(Math.Min(indice, tarefas.Count - 1)); // seleciona o vizinho
    tslStatus.Text = "Tarefa removida.";
}

private void AtualizarLista(int selecionar = -1)         // reconstrói o ListBox a partir da lista
{
    lstTarefas.Items.Clear();
    foreach (var t in tarefas)
        lstTarefas.Items.Add(t);                         // Add(objeto): o controle guarda o objeto inteiro

    if (selecionar >= 0 && selecionar < lstTarefas.Items.Count)
        lstTarefas.SelectedIndex = selecionar;

    int feitas = tarefas.Count(t => t.Concluida);        // LINQ: conta as concluídas
    lblContador.Text = $"{feitas} de {tarefas.Count} concluída(s)";
}
🧪 Perguntas: por que existe a lista tarefas se o ListBox já guarda os itens? Desafio: mostre as tarefas concluídas em cinza (dica: DrawMode = OwnerDrawFixed e o evento DrawItem).

// ---------- Produto.cs ----------
public class Produto
{
    public string Nome { get; }
    public decimal Preco { get; }
    public int Quantidade { get; private set; }
    public bool EstoqueBaixo => Quantidade < 5;          // regra no lugar certo: na classe

    public Produto(string nome, decimal preco, int quantidade)
    {
        if (string.IsNullOrWhiteSpace(nome)) throw new ArgumentException("Informe o nome do produto.");
        if (preco <= 0) throw new ArgumentException("O preço deve ser maior que zero.");
        if (quantidade < 0) throw new ArgumentException("A quantidade não pode ser negativa.");
        Nome = nome.Trim();
        Preco = preco;
        Quantidade = quantidade;
    }

    public void Entrada(int qtd)
    {
        if (qtd <= 0) throw new ArgumentException("A quantidade deve ser maior que zero.");
        Quantidade += qtd;
    }

    public void Saida(int qtd)
    {
        if (qtd <= 0) throw new ArgumentException("A quantidade deve ser maior que zero.");
        if (qtd > Quantidade) throw new InvalidOperationException("Estoque insuficiente para essa saída.");
        Quantidade -= qtd;
    }
}

// ---------- FrmEstoque.cs ----------
private readonly BindingList<Produto> produtos = new();   // a grade ATUALIZA SOZINHA ao adicionar/remover itens

private Produto? Selecionado => dgvProdutos.CurrentRow?.DataBoundItem as Produto;   // propriedade auxiliar; ?. evita nulo

    dgvProdutos.Columns[nameof(Produto.Quantidade)].HeaderText = "Qtd.";

}

// Executa uma ação e transforma exceções de REGRA em mensagem na barra de status (evita repetir try/catch)
private void Tentar(Action acao)
{
    try
    {
        acao();
    }
    catch (Exception ex) when (ex is ArgumentException or InvalidOperationException)
    {
        tslStatus.Text = ex.Message;
    }
}

private void btnAdicionar_Click(object sender, EventArgs e)

        tslStatus.Text = $"Produto \"{txtNome.Text.Trim()}\" adicionado.";
        txtNome.Clear();
        nudPreco.Value = 0;
        nudQuantidade.Value = 0;
        txtNome.Focus();
    });
}

private void btnEntrada_Click(object sender, EventArgs e) => Movimentar(entrada: true);
private void btnSaida_Click(object sender, EventArgs e) => Movimentar(entrada: false);

private void Movimentar(bool entrada)                    // um só método para as duas operações

// ---------- Conta.cs (classe base abstrata e filhas) ----------
public abstract class Conta
{
    private readonly List<string> extrato = new();       // linhas do extrato (privada)

    public string Titular { get; }
    public decimal Saldo { get; protected set; }         // protected set: a base E as filhas alteram
    public abstract decimal Limite { get; }              // cada tipo define o seu limite (POLIMORFISMO)
    public abstract string Tipo { get; }                 // texto mostrado na grade
    public IReadOnlyList<string> Extrato => extrato;     // visão somente leitura

    protected Conta(string titular)
    {
        if (string.IsNullOrWhiteSpace(titular)) throw new ArgumentException("Informe o titular.");
        Titular = titular.Trim();
    }

    public void Depositar(decimal valor)
    {
        ValidarValor(valor);
        Saldo += valor;
        Registrar("Depósito", valor);
    }

    public void Sacar(decimal valor)
    {
        ValidarValor(valor);
        if (valor > Saldo + Limite)                      // usa o Limite da classe REAL (corrente ou poupança)
            throw new InvalidOperationException($"Saldo insuficiente. Disponível: {Saldo + Limite:C2}.");
        Saldo -= valor;
        Registrar("Saque", valor);
    }

    protected void Registrar(string operacao, decimal valor)   // as filhas também registram
        => extrato.Add($"{DateTime.Now:dd/MM HH:mm}  {operacao,-10} {valor,12:C2}   Saldo {Saldo,12:C2}");

    private static void ValidarValor(decimal valor)
    {
        if (valor <= 0) throw new ArgumentException("O valor deve ser maior que zero.");

// ---------- Forma.cs ----------
public abstract class Forma
{
    protected const int Escala = 3;                      // pixels por unidade (para caber na tela)

    public string Nome { get; }
    public Color Cor { get; }

    protected Forma(string nome, Color cor)
    {
        Nome = nome;
        Cor = cor;
    }

    public abstract double Area();                       // cada forma calcula do seu jeito
    public abstract double Perimetro();
    public abstract int Desenhar(Graphics g, int x, int y);   // desenha e devolve a LARGURA ocupada em pixels

    public override string ToString() => $"{Nome,-10} área {Area(),8:F2}  perím. {Perimetro(),8:F2}";
}

public class Circulo : Forma
{
    private readonly double raio;

    public Circulo(double raio, Color cor) : base("Círculo", cor)
    {
        if (raio <= 0) throw new ArgumentException("O raio deve ser maior que zero.");
        this.raio = raio;
    }

    public override double Area() => Math.PI * raio * raio;
    public override double Perimetro() => 2 * Math.PI * raio;

    public override int Desenhar(Graphics g, int x, int y)
    {
        int diametro = (int)(2 * raio * Escala);         // converte unidades em pixels
        using var pincel = new SolidBrush(Cor);          // "pincel" com a cor da forma (using libera o recurso)
        g.FillEllipse(pincel, x, y, diametro, diametro); // elipse com largura = altura = círculo
        return diametro;
    }
}

public class Retangulo : Forma
{
    private readonly double largura, altura;

    public Retangulo(double largura, double altura, Color cor) : base("Retângulo", cor)
    {
        if (largura <= 0 || altura <= 0) throw new ArgumentException("Largura e altura devem ser maiores que zero.");
        this.largura = largura;
        this.altura = altura;
    }

    public override double Area() => largura * altura;
    public override double Perimetro() => 2 * (largura + altura);

    public override int Desenhar(Graphics g, int x, int y)
    {
        int larguraPx = (int)(largura * Escala);
        using var pincel = new SolidBrush(Cor);
        g.FillRectangle(pincel, x, y, larguraPx, (int)(altura * Escala));
        return larguraPx;
    }
}

public class Contato
{
    public string Nome { get; set; } = "";               // set público: necessário para o JSON reconstruir o objeto
    public string Telefone { get; set; } = "";
    public string Email { get; set; } = "";

public class Agenda
{
    private readonly List<Contato> contatos = new();

    public int Total => contatos.Count;

    public void Adicionar(Contato c)
    {
        if (string.IsNullOrWhiteSpace(c.Nome)) throw new ArgumentException("Informe o nome.");
        if (!c.Email.Contains('@')) throw new ArgumentException("Informe um e-mail válido.");
        if (contatos.Any(x => x.Email.Equals(c.Email, StringComparison.OrdinalIgnoreCase)))   // ignora maiúsculas
            throw new InvalidOperationException("Já existe um contato com esse e-mail.");
        contatos.Add(c);
    }

    public bool Remover(Contato c) => contatos.Remove(c);

    public IEnumerable<Contato> Buscar(string termo)     // LINQ: filtra e ordena
        => contatos
            .Where(c => c.Nome.Contains(termo, StringComparison.OrdinalIgnoreCase)
                     || c.Email.Contains(termo, StringComparison.OrdinalIgnoreCase))
            .OrderBy(c => c.Nome);

    public void Salvar(string caminho)
    {
        string json = JsonSerializer.Serialize(contatos, new JsonSerializerOptions { WriteIndented = true });   // objetos -> texto
        File.WriteAllText(caminho, json);                // grava o arquivo
    }

    public void Carregar(string caminho)
    {
        var lista = JsonSerializer.Deserialize<List<Contato>>(File.ReadAllText(caminho)) ?? new();   // texto -> objetos
        contatos.Clear();
        contatos.AddRange(lista);
    }
}

// ---------- Jogo.cs ----------
public enum Resultado { Acertou, MuitoBaixo, MuitoAlto }   // valores nomeados em vez de números soltos

public class Jogo
{
    public const int Maximo = 100;                       // maior número possível
    private readonly int segredo;

    public int Tentativas { get; private set; }          // o objeto "lembra" seu estado
    public int Segredo => segredo;

    public Jogo()
    {
        segredo = Random.Shared.Next(1, Maximo + 1);     // sorteia de 1 a 100 (o limite superior não entra)
    }

    public Resultado Tentar(int palpite)
    {
        Tentativas++;
        if (palpite == segredo) return Resultado.Acertou;
        return palpite < segredo ? Resultado.MuitoBaixo : Resultado.MuitoAlto;
    }
}

    decimal mediaTurma = alunos.Average(a => a.Media);   // LINQ
    int aprovados = alunos.Count(a => a.Situacao == "Aprovado");
    lblResumo.Text = $"Alunos: {alunos.Count} | Média da turma: {mediaTurma:F2} | Aprovados: {aprovados}";
}

private void btnExportar_Click(object sender, EventArgs e)
{
    if (alunos.Count == 0) { tslStatus.Text = "Não há dados para exportar."; return; }

    using var dlg = new SaveFileDialog { Filter = "CSV (*.csv)|*.csv", FileName = "boletim.csv" };
    if (dlg.ShowDialog() != DialogResult.OK) return;

    var linhas = new List<string> { "Nome;Nota1;Nota2;Nota3;Media;Situacao" };      // cabeçalho (";" abre direto no Excel pt-BR)
    linhas.AddRange(alunos.Select(a => $"{a.Nome};{a.Nota1};{a.Nota2};{a.Nota3};{a.Media:F2};{a.Situacao}"));   // 1 linha por aluno

    try
    {
        File.WriteAllLines(dlg.FileName, linhas, Encoding.UTF8);   // UTF8 preserva os acentos
        tslStatus.Text = "Arquivo exportado.";
    }
    catch (IOException ex)                               // arquivo aberto em outro programa, por exemplo
    {
        MessageBox.Show(ex.Message, "Erro ao exportar", MessageBoxButtons.OK, MessageBoxIcon.Error);
    }
}

Laboratório · Interface travada × responsiva

Crie um projeto FrmResponsivo com btnBloquear, btnAsync, btnCalculo, um ProgressBar pgbProgresso, um Label lblStatus e um TextBox para você tentar digitar durante os testes. Clique em cada botão e tente digitar, arrastar a janela e clicar enquanto ele trabalha.

// ---------- Formulário FrmResponsivo ----------
private void btnBloquear_Click(object sender, EventArgs e)
{
    lblStatus.Text = "Trabalhando (bloqueado)...";       // o texto NÃO aparece, pois a tela só é repintada depois
    Thread.Sleep(5000);                                  // BLOQUEIA a thread da interface por 5 s: tela congelada
    lblStatus.Text = "Concluído!";
}

private async void btnAsync_Click(object sender, EventArgs e)    // async: o método pode "esperar" sem travar a tela
{
    btnAsync.Enabled = false;                            // evita cliques repetidos durante a operação
    lblStatus.Text = "Trabalhando (assíncrono)...";
    for (int i = 1; i <= 50; i++)
    {
        await Task.Delay(100);                           // await: libera a interface e volta aqui depois de 100 ms
        pgbProgresso.Value = i * 2;                      // atualiza a barra; a janela continua viva
    }
    lblStatus.Text = "Concluído!";
    btnAsync.Enabled = true;
}

private async void btnCalculo_Click(object sender, EventArgs e)
{
    lblStatus.Text = "Calculando...";
    long soma = await Task.Run(() =>                     // Task.Run executa em OUTRA thread; await aguarda sem travar
    {
        long total = 0;
        for (long i = 1; i <= 2_000_000_000; i++) total += i;     // cálculo pesado
        // lblStatus.Text = "x";                         // DESCOMENTE: InvalidOperationException (acesso entre threads)
        return total;
    });
    lblStatus.Text = $"Soma: {soma:N0}";                 // aqui já voltamos à thread da interface: pode mexer nos controles
}

Laboratório · Depuração de eventos e erros globais

  1. Coloque um ponto de interrupção (F9) dentro de btnCadastrar_Click (Projeto 1) e execute com F5. Clique no botão: a execução para na linha.
  2. Passe o mouse sobre txtIdade.Text e idade; use F10 linha a linha e F11 para entrar no construtor de Pessoa.
  3. Abra Depurar → Janelas → Pilha de Chamadas: veja a cadeia Application.Run → ... → seu evento.
  4. Provoque um erro não tratado (por exemplo, int.Parse("abc") sem try) e observe o que acontece com e sem o tratamento global abaixo (execute o .exe da pasta bin\\Debug fora do Visual Studio para ver o comportamento do usuário).
// ---------- Program.cs ----------
static class Program
{
    [STAThread]
    static void Main()
    {
        ApplicationConfiguration.Initialize();

        // Deve vir ANTES de criar o primeiro formulário: manda as exceções da interface para o nosso manipulador
        Application.SetUnhandledExceptionMode(UnhandledExceptionMode.CatchException);

        Application.ThreadException += (sender, e) =>    // roda quando uma exceção NÃO tratada acontece em um evento
        {
            File.AppendAllText("erros.log",              // registra em arquivo para investigar depois
                $"{DateTime.Now:yyyy-MM-dd HH:mm:ss} {e.Exception}\n\n");
            MessageBox.Show("Ocorreu um erro inesperado e foi registrado.\n" + e.Exception.Message,
                "Erro", MessageBoxButtons.OK, MessageBoxIcon.Error);
        };

        Application.Run(new FrmCadastroPessoa());        // troque pelo formulário inicial do seu projeto
    }
}

Laboratório · Publicar o aplicativo

  1. Mude a configuração para Release (lista na barra de ferramentas).
  2. Clique direito no projeto → Publicar → Destino: Pasta → escolha a pasta (ex.: C:\\Publicacao\\Estoque) → Concluir.
  3. Em Mostrar todas as configurações, escolha: Modo de implantação (dependente de framework ou autocontido) e o Runtime de destino (win-x64).
  4. Clique em Publicar e abra a pasta: localize o .exe.
  5. Copie a pasta para outro computador (ou uma máquina virtual) e execute. Se for dependente de framework e der erro, instale o .NET Desktop Runtime correspondente.
  6. Anote o tamanho da pasta nos dois modos e compare.

Opcional: defina um ícone do aplicativo (Propriedades do projeto → Aplicativo → Ícone) e a versão (Pacote).
