3. Teste de mesa (exercícios)

  1. Qual a saída? 
    int x = 10, y = 3;
Console.WriteLine(x / y);
Console.WriteLine(x % y);
Console.WriteLine((double)x / y);
Console.WriteLine(x > y && y > 5);
  2. Faça o teste de mesa e diga a saída: 
    int n = 5, f = 1;
while (n > 1)
{
    f *= n;
    n--;
}
Console.WriteLine(f);
  3. Quantas vezes “Oi” é escrito? 
    for (int i = 0; i < 3; i++)
    for (int j = 0; j < 4; j++)
        Console.WriteLine("Oi");
  4. Esta função deveria dizer se um número é positivo, mas tem um defeito. Encontre e corrija: 
    static bool EhPositivo(int n)
{
    if (n > 0) return true;
    else return false;
    Console.WriteLine("Verificado");
}
Ver respostas
  1. 3 · 1 · 3,3333... · False (10 > 3 é verdadeiro, 3 > 5 é falso).
  2. 120 (5 × 4 × 3 × 2).
  3. 12 vezes (3 × 4).
  4. A linha Console.WriteLine("Verificado") é código inalcançável, pois os dois caminhos já retornaram. O compilador avisa. Remova a linha, e a função pode ser simplificada para return n > 0;.

8. Glossário

TermoSignificado
AlgoritmoSequência finita de passos que resolve um problema
VariávelEspaço nomeado da memória que guarda um valor
ConstanteValor que não muda durante a execução
AtribuiçãoGuardar um valor em uma variável (=)
CondiçãoExpressão que resulta em verdadeiro ou falso
Laço (loop)Estrutura que repete um bloco
Contador / acumuladorVariável que conta / soma a cada repetição
SentinelaValor especial que indica o fim da leitura
Vetor / matrizConjunto de valores acessados por índice(s)
Função (método)Bloco de código reutilizável com nome
Parâmetro / argumentoVariável da declaração / valor passado na chamada
RecursãoFunção que chama a si mesma
ExceçãoErro em tempo de execução
Teste de mesaExecução manual do algoritmo, anotando as variáveis
DepurarEncontrar e corrigir a causa de um defeito
