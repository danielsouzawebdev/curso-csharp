1. Algoritmos e lógica de programação

Algoritmo é uma sequência finita e ordenada de passos claros que resolve um problema. Uma receita de bolo e as instruções de um caixa eletrônico são algoritmos. Lógica de programação é a técnica de encadear esses passos de forma correta.

Um bom algoritmo é preciso (sem ambiguidade), finito (termina) e correto (resolve o problema para todas as entradas válidas).

Três formas de representar

O C# é uma linguagem multiparadigma: você usa o estilo estruturado dentro dos métodos de qualquer programa orientado a objetos. Por isso este módulo é a base de tudo o que vem depois.

As três estruturas básicas

  • Sequência: as instruções executam uma após a outra, de cima para baixo.
  • Decisão (seleção): o programa escolhe um caminho conforme uma condição (if, switch).
  • Repetição (iteração): um trecho executa várias vezes (for, while...).

6. Estruturas de decisão

  • if: executa o bloco se a condição for verdadeira.
  • if ... else: escolhe entre dois caminhos.
  • else if: encadeia várias condições (a primeira verdadeira vence; o resto é ignorado).
  • Operador ternário: texto = nota >= 7 ? "Aprovado" : "Reprovado";
  • switch: escolhe entre valores exatos de uma variável (precisa de break em cada case; default trata o restante).
// if / else if / else
if (media >= 7)
{
    Console.WriteLine("Aprovado");
}
else if (media >= 5)
{
    Console.WriteLine("Recuperação");
}
else
{
    Console.WriteLine("Reprovado");
}

// switch clássico
switch (opcao)
{
    case 1:
        Console.WriteLine("Somar");
        break;
    case 2:
        Console.WriteLine("Subtrair");
        break;
    default:
        Console.WriteLine("Opção inválida");
        break;
}

// switch expression (forma moderna e curta, devolve um valor)
string nomeDia = dia switch
{
    1 => "Domingo",
    2 => "Segunda",
    _ => "Outro"      // _ = qualquer outro valor
};

8. Vetores, matrizes e listas

  • Vetor (array): conjunto de itens do mesmo tipo e tamanho fixo, acessados por índice que começa em 0. double[] notas = new double[5]; → índices 0 a 4. notas.Length devolve o tamanho.
  • Acessar índice inexistente causa IndexOutOfRangeException.
  • Matriz: vetor de duas dimensões: int[,] tabela = new int[3, 3];, acessada por tabela[linha, coluna].
  • Lista List<T>: como um vetor que cresce: Add, Remove, RemoveAt, Count, Contains, IndexOf.

9. Funções (métodos)

Uma função é um bloco de código com nome, que pode receber dados (parâmetros) e devolver um resultado (retorno). Benefícios: reutilização, legibilidade, facilidade de testar e de corrigir (divisão em partes menores).

// Tipo de retorno, nome, parâmetros entre parênteses
static double CalcularMedia(double nota1, double nota2)
{
    return (nota1 + nota2) / 2;    // return devolve o valor e encerra a função
}

static void MostrarLinha()         // void = não devolve nada
{
    Console.WriteLine("----------");
}

double m = CalcularMedia(8, 6);    // chamada: 8 e 6 são os ARGUMENTOS
  • Parâmetro é a variável da declaração; argumento é o valor passado na chamada.
  • Escopo local: variáveis criadas dentro da função não existem fora dela.
  • Parâmetro opcional: double desconto = 10.
  • Sobrecarga: funções com o mesmo nome e parâmetros diferentes (Area(raio) e Area(base, altura)).
  • Recursão: a função chama a si mesma, precisando de uma condição de parada (fatorial: n * Fatorial(n - 1)).
  • Boa prática: cada função faz uma única coisa, com nome de verbo (CalcularMedia, LerInteiro).

11. Tratamento de erros e validação

Quando algo dá errado em tempo de execução, o C# lança uma exceção. Se ninguém a tratar, o programa fecha.

try                                   // tenta executar
{
    int idade = int.Parse(Console.ReadLine() ?? "");
    Console.WriteLine(10 / idade);
}
catch (FormatException)               // o texto não era um número
{
    Console.WriteLine("Digite apenas números.");
}
catch (DivideByZeroException)         // divisão por zero
{
    Console.WriteLine("Idade zero não é permitida aqui.");
}
finally                               // roda SEMPRE, com ou sem erro
{
    Console.WriteLine("Fim do trecho.");
}

Regra: para entrada do usuário, valide antes (TryParse, if) em vez de apenas capturar o erro. Exceções são para situações realmente excepcionais.

Exceção comumCausa

DivideByZeroExceptionDivisão inteira por zero
IndexOutOfRangeExceptionÍndice fora do vetor
NullReferenceExceptionUsar uma variável que está null
OverflowExceptionNúmero grande demais para o tipo

13. Estilo, formatação e comentários

  • Indentação de 4 espaços e uma instrução por linha. No Visual Studio: Ctrl+K, Ctrl+D formata o arquivo.
  • Nomes que dizem o que a coisa é ou faz.
  • Comentários explicam o porquê, e não o óbvio; comentar/descomentar linhas: Ctrl+K, Ctrl+C / Ctrl+K, Ctrl+U.
  • Evite repetir código: repetiu, vire função ou laço.
  • Evite “números mágicos”: use const com nome.

14. Método para resolver problemas

  1. Entender: quais são as entradas, as saídas e as regras? Dê exemplos.
  2. Planejar: escreva o algoritmo (fluxograma ou pseudocódigo).
  3. Codificar em pequenos pedaços, testando cada um.
  4. Testar com valores normais, limites e inválidos.
  5. Melhorar: nomes, comentários, funções.
