Prática guiada · 8 projetos de console

🧭 Como executar esta práticaDigite o código, execute a cada etapa e compare o comportamento com o resultado descrito. Se houver erro, leia a mensagem antes de alterar o código e use o depurador quando indicado.

Faça os projetos na ordem. Cada um é um novo Aplicativo de Console. Digite o código (não copie e cole), leia cada comentário, execute, faça os testes sugeridos e responda às perguntas. Quando o programa for “quebrado de propósito”, observe a mensagem de erro: ela ensina muito.

💡 Códigos para .NET 6 ou superior (modelo com instruções de nível superior no Program.cs). Se o seu modelo mostrar class Program e Main, coloque o código dentro de static void Main().

Prepare o ambiente de trabalho

  1. Visual Studio → Criar um projeto → Aplicativo de Console (C#) → Avançar.
  2. Nome: Projeto01Ola; local: C:\Projetos\Modulo1 → Avançar → escolha o .NET LTS → Criar.
  3. Abra o Program.cs, apague o conteúdo e digite o código do projeto.
  4. Execute com Ctrl+F5 (executa e mantém a janela aberta) ou F5 (com depuração).
  5. Dica: guarde tudo em uma solução com vários projetos (clique direito na solução → Adicionar → Novo Projeto). Para escolher qual roda, clique direito no projeto → Definir como Projeto de Inicialização.
  6. Crie um repositório Git e faça um commit ao fim de cada projeto.

Projeto 2 · Situação do aluno (decisão)

Objetivo: usar if / else if / else e operadores lógicos, validando as entradas. Antes de codificar, desenhe o fluxograma da decisão. Casos de teste: (8, 6, 80) → Aprovado; (5, 5, 90) → Recuperação; (3, 4, 100) → Reprovado por nota; (10, 10, 70) → Reprovado por falta; (11, 5, 80) → erro de faixa; (abc, 5, 80) → erro de número.

Console.OutputEncoding = System.Text.Encoding.UTF8;

Console.WriteLine("=== Situação do aluno ===");

Console.Write("Nota 1 (0 a 10): ");
bool ok1 = double.TryParse(Console.ReadLine(), out double nota1);   // TryParse devolve true/false e entrega o número em "nota1"
Console.Write("Nota 2 (0 a 10): ");
bool ok2 = double.TryParse(Console.ReadLine(), out double nota2);
Console.Write("Frequência (%): ");
bool ok3 = double.TryParse(Console.ReadLine(), out double frequencia);

if (!ok1 || !ok2 || !ok3)                             // ! = NÃO; || = OU: se QUALQUER conversão falhou...
{
    Console.WriteLine("Digite apenas números.");      // ...avisa
    return;                                           // return em Program.cs encerra o programa
}

if (nota1 < 0 || nota1 > 10 || nota2 < 0 || nota2 > 10)   // validação de faixa: notas fora de 0 a 10
{
    Console.WriteLine("As notas devem estar entre 0 e 10.");
    return;
}

if (frequencia < 0 || frequencia > 100)               // frequência é uma porcentagem
{
    Console.WriteLine("A frequência deve estar entre 0 e 100.");
    return;
}

double media = (nota1 + nota2) / 2;                   // parênteses garantem somar ANTES de dividir
string situacao;                                      // declarada sem valor; será definida abaixo

if (frequencia < 75)                                  // a falta vem primeiro: reprova independentemente da nota
{
    situacao = "Reprovado por falta";
}
else if (media >= 7)                                  // só chega aqui se frequencia >= 75
{
    situacao = "Aprovado";
}
else if (media >= 5)                                  // só chega aqui se media < 7
{
    situacao = "Recuperação";
}
else                                                  // todo o resto: media < 5
{
    situacao = "Reprovado por nota";
}

Console.WriteLine($"Média: {media:F1}");              // F1 = 1 casa decimal
Console.WriteLine($"Frequência: {frequencia}%");
Console.WriteLine($"Situação: {situacao}");

Projeto 3 · Tabuada, soma e asteriscos (repetição)

Objetivo: usar for, do-while com sentinela, contador, acumulador e laços aninhados. Faça o teste de mesa da Parte 2 com a entrada 4, 6, 0.

Console.OutputEncoding = System.Text.Encoding.UTF8;

// ---------- PARTE 1: tabuada com FOR (sabemos que são 10 voltas) ----------
Console.Write("Tabuada de qual número? ");
if (!int.TryParse(Console.ReadLine(), out int n))     // valida a entrada
{
    Console.WriteLine("Número inválido.");
    return;
}

for (int i = 1; i <= 10; i++)                         // i começa em 1; repete enquanto i <= 10; i++ soma 1 a cada volta
{
    Console.WriteLine($"{n} x {i,2} = {n * i,3}");    // ,2 e ,3 alinham os números à direita em colunas
}

// ---------- PARTE 2: soma com sentinela usando DO-WHILE ----------
int soma = 0;                                         // ACUMULADOR: guarda o total
int contador = 0;                                     // CONTADOR: guarda quantos números foram digitados
int valor;                                            // vai receber cada número lido

Console.WriteLine("\nDigite números inteiros (0 para terminar):");
do                                                    // do-while executa pelo menos uma vez
{
    Console.Write("Número: ");
    if (!int.TryParse(Console.ReadLine(), out valor)) // se não for número...
    {
        Console.WriteLine("Valor inválido.");
        valor = -1;                                   // garante que o laço continue (não é zero)
        continue;                                     // volta ao teste da condição, pulando o resto
    }
    if (valor != 0)                                   // o zero é só o sinal de fim: não entra na soma
    {
        soma += valor;                                // soma = soma + valor
        contador++;                                   // contador = contador + 1
    }
} while (valor != 0);                                 // repete enquanto o usuário não digitar 0

if (contador > 0)                                     // evita dividir por zero se nada foi digitado
{
    double media = (double)soma / contador;           // (double) converte ANTES da divisão, para não perder os decimais
    Console.WriteLine($"Soma: {soma} | Quantidade: {contador} | Média: {media:F2}");
}
else
{
    Console.WriteLine("Nenhum número foi informado.");
}

// ---------- PARTE 3: laços ANINHADOS (um dentro do outro) ----------
Console.WriteLine();
for (int linha = 1; linha <= 5; linha++)              // laço de fora: controla as linhas
{
    for (int coluna = 1; coluna <= linha; coluna++)   // laço de dentro: quantos asteriscos nesta linha
    {
        Console.Write("*");                           // escreve sem pular de linha
    }
    Console.WriteLine();                              // ao terminar a linha, pula para a próxima
}

Projeto 4 · Calculadora com menu (switch e do-while)

Objetivo: criar um menu que se repete até o usuário sair, usando switch, break e continue. Teste: opção inválida, letras no lugar de números e divisão por zero.

Console.OutputEncoding = System.Text.Encoding.UTF8;

string opcao;                                         // guarda a escolha do usuário

do                                                    // o menu aparece pelo menos uma vez
{
    Console.WriteLine("\n=== CALCULADORA ===");
    Console.WriteLine("1 - Somar");
    Console.WriteLine("2 - Subtrair");
    Console.WriteLine("3 - Multiplicar");
    Console.WriteLine("4 - Dividir");
    Console.WriteLine("0 - Sair");
    Console.Write("Escolha: ");
    opcao = Console.ReadLine() ?? "";                 // lê a opção como texto

    if (opcao == "0")                                 // quer sair?
    {
        break;                                        // break sai do laço do-while
    }

    if (opcao != "1" && opcao != "2" && opcao != "3" && opcao != "4")  // && = E: nenhuma das opções válidas
    {
        Console.WriteLine("Opção inválida.");
        continue;                                     // volta ao início do menu
    }

    Console.Write("Primeiro número: ");
    bool okA = double.TryParse(Console.ReadLine(), out double a);
    Console.Write("Segundo número: ");
    bool okB = double.TryParse(Console.ReadLine(), out double b);

    if (!okA || !okB)                                 // alguma conversão falhou
    {
        Console.WriteLine("Digite apenas números.");
        continue;
    }

    switch (opcao)                                    // escolhe o cálculo conforme a opção
    {
        case "1":
            Console.WriteLine($"{a} + {b} = {a + b}");
            break;                                    // break sai do switch (não do laço)
        case "2":
            Console.WriteLine($"{a} - {b} = {a - b}");
            break;
        case "3":
            Console.WriteLine($"{a} x {b} = {a * b}");
            break;
        case "4":
            if (b == 0)                               // divisão por zero não é permitida
            {
                Console.WriteLine("Não é possível dividir por zero.");
            }
            else
            {
                Console.WriteLine($"{a} / {b} = {a / b:F2}");
            }
            break;
    }
} while (opcao != "0");                               // repete até o usuário escolher sair

Console.WriteLine("Programa encerrado.");

Projeto 5 · Jogo de adivinhação (while e Random)

Objetivo: repetição com duas condições e uma “bandeira” booleana. Perguntas: por que a entrada inválida não gasta tentativa? O que muda se trocarmos && por || na condição do while? (Teste!)

Console.OutputEncoding = System.Text.Encoding.UTF8;

const int MaxTentativas = 7;                          // const: valor fixo, com nome (evita "número mágico")
var sorteio = new Random();                           // objeto que gera números aleatórios
int segredo = sorteio.Next(1, 101);                   // Next(1, 101) sorteia de 1 até 100 (o limite superior NÃO entra)
int tentativas = 0;                                   // contador de tentativas usadas
bool acertou = false;                                 // "bandeira": vira true quando o jogador acerta

Console.WriteLine($"Adivinhe o número de 1 a 100. Você tem {MaxTentativas} tentativas.");

while (tentativas < MaxTentativas && !acertou)        // continua enquanto restam tentativas E ainda não acertou
{
    Console.Write($"Tentativa {tentativas + 1}/{MaxTentativas}: ");

    if (!int.TryParse(Console.ReadLine(), out int palpite) || palpite < 1 || palpite > 100)
    {
        Console.WriteLine("Digite um número inteiro de 1 a 100.");
        continue;                                     // entrada inválida NÃO gasta tentativa
    }

    tentativas++;                                     // só conta tentativas válidas

    if (palpite == segredo)                           // == compara (um = só atribui)
    {
        acertou = true;
    }
    else if (palpite < segredo)
    {
        Console.WriteLine("Tente um número MAIOR.");
    }
    else
    {
        Console.WriteLine("Tente um número MENOR.");
    }
}

if (acertou)                                          // resultado final
{
    Console.WriteLine($"Parabéns! Você acertou em {tentativas} tentativa(s).");
}
else
{
    Console.WriteLine($"Fim de jogo! O número era {segredo}.");
}

Projeto 6 · Estatísticas de notas (vetores e matrizes)

Objetivo: guardar vários valores em um vetor, percorrer com for e foreach, calcular média, maior e menor, ordenar e usar uma matriz. Teste com notas 8, 6, 9, 4, 7.

Console.OutputEncoding = System.Text.Encoding.UTF8;

const int Quantidade = 5;                             // quantidade de alunos
double[] notas = new double[Quantidade];              // vetor de 5 posições, índices 0 a 4 (começam com 0.0)

// ---------- leitura com validação ----------
for (int i = 0; i < notas.Length; i++)                // Length = tamanho do vetor (5)
{
    double valor;
    Console.Write($"Nota do aluno {i + 1}: ");        // i + 1 porque as pessoas contam a partir de 1
    while (!double.TryParse(Console.ReadLine(), out valor) || valor < 0 || valor > 10)
    {
        Console.Write("Inválido. Digite um número de 0 a 10: ");   // repete a pergunta até a resposta ser válida
    }
    notas[i] = valor;                                 // guarda na posição i
}

// ---------- estatísticas com FOREACH ----------
double soma = 0;                                      // acumulador
double maior = notas[0];                              // começa com o primeiro valor
double menor = notas[0];
int aprovados = 0;                                    // contador

foreach (double nota in notas)                        // percorre cada item do vetor, do primeiro ao último
{
    soma += nota;
    if (nota > maior) maior = nota;                   // achou um maior: atualiza
    if (nota < menor) menor = nota;                   // achou um menor: atualiza
    if (nota >= 7) aprovados++;
}

double media = soma / notas.Length;
int acimaDaMedia = 0;
for (int i = 0; i < notas.Length; i++)                // segunda passada: só pode comparar com a média depois de calculá-la
{
    if (notas[i] > media) acimaDaMedia++;
}

Console.WriteLine($"\nMédia: {media:F2} | Maior: {maior:F1} | Menor: {menor:F1}");
Console.WriteLine($"Aprovados: {aprovados} de {Quantidade} | Acima da média: {acimaDaMedia}");

Array.Sort(notas);                                    // ordena o vetor do menor para o maior
Console.WriteLine("Notas em ordem: " + string.Join(" | ", notas));   // Join une os itens em um texto

// ---------- MATRIZ: tabela de multiplicação 3x3 ----------
int[,] tabela = new int[3, 3];                        // 3 linhas e 3 colunas
for (int linha = 0; linha < tabela.GetLength(0); linha++)          // GetLength(0) = número de linhas
{
    for (int coluna = 0; coluna < tabela.GetLength(1); coluna++)   // GetLength(1) = número de colunas
    {
        tabela[linha, coluna] = (linha + 1) * (coluna + 1);        // preenche cada célula
        Console.Write($"{tabela[linha, coluna],4}");               // imprime alinhado em 4 colunas
    }
    Console.WriteLine();
}

Projeto 7 · Biblioteca de funções

Objetivo: criar e reutilizar funções com parâmetros e retorno, recursão, sobrecarga e parâmetro opcional. Cada linha de saída traz o valor esperado em comentário: o programa funciona como um teste manual. Observe que EhPalindromo reutiliza Inverter.

Console.OutputEncoding = System.Text.Encoding.UTF8;

// Program.cs: só CHAMA as funções. A biblioteca fica na classe abaixo.
Console.WriteLine($"Fatorial de 5 (laço):       {Utilitarios.Fatorial(5)}");            // esperado: 120
Console.WriteLine($"Fatorial de 5 (recursão):    {Utilitarios.FatorialRecursivo(5)}");   // esperado: 120
Console.WriteLine($"7 é primo?                   {Utilitarios.EhPrimo(7)}");             // esperado: True
Console.WriteLine($"9 é primo?                   {Utilitarios.EhPrimo(9)}");             // esperado: False
Console.WriteLine($"Fibonacci(10):               {Utilitarios.Fibonacci(10)}");          // esperado: 55
Console.WriteLine($"Inverter(\"C#\"):              {Utilitarios.Inverter("C#")}");        // esperado: #C
Console.WriteLine($"\"Socorram-me, subi no ônibus em Marrocos\" é palíndromo? " +
                  $"{Utilitarios.EhPalindromo("Socorram-me, subi no ônibus em Marrocos")}");   // esperado: True
Console.WriteLine($"Área do círculo (raio 2):    {Utilitarios.Area(2):F2}");             // esperado: 12,57
Console.WriteLine($"Área do retângulo (3 x 4):   {Utilitarios.Area(3, 4)}");             // esperado: 12
Console.WriteLine($"Preço com 10% (padrão):      {Utilitarios.AplicarDesconto(200):F2}");     // esperado: 180,00
Console.WriteLine($"Preço com 25%:               {Utilitarios.AplicarDesconto(200, 25):F2}"); // esperado: 150,00

// Uma classe "static" agrupa funções que não guardam dados. Ela fica DEPOIS das instruções do Program.cs.
static class Utilitarios
{
    public static long Fatorial(int n)                // public: pode ser chamada de fora; static: usada sem criar objeto
    {
        if (n < 0)                                    // fatorial de negativo não existe
            throw new ArgumentException("n deve ser maior ou igual a zero.");
        long resultado = 1;                           // elemento neutro da multiplicação
        for (int i = 2; i <= n; i++)                  // multiplica 2 x 3 x ... x n
        {
            resultado *= i;                           // resultado = resultado * i
        }
        return resultado;                             // devolve o valor calculado
    }

    public static long FatorialRecursivo(int n)       // mesma ideia, usando RECURSÃO
    {
        if (n <= 1) return 1;                         // CONDIÇÃO DE PARADA: sem ela, a função chamaria a si mesma para sempre
        return n * FatorialRecursivo(n - 1);          // n! = n x (n-1)!
    }

    public static bool EhPrimo(int n)
    {
        if (n < 2) return false;                      // 0, 1 e negativos não são primos
        for (int i = 2; i * i <= n; i++)              // basta testar divisores até a raiz quadrada de n
        {
            if (n % i == 0) return false;             // % é o resto: se divide exatamente, não é primo; sai logo
        }
        return true;                                  // ninguém dividiu: é primo
    }

    public static int Fibonacci(int n)                // 0, 1, 1, 2, 3, 5, 8, ... (versão iterativa)
    {
        int anterior = 0, atual = 1;                  // os dois primeiros termos
        for (int i = 0; i < n; i++)                   // avança n posições
        {
            int proximo = anterior + atual;           // próximo termo = soma dos dois últimos
            anterior = atual;                         // desliza a "janela" de dois termos
            atual = proximo;
        }
        return anterior;                              // após n passos, "anterior" guarda Fibonacci(n)
    }

    public static string Inverter(string texto)
    {
        char[] letras = texto.ToCharArray();          // converte o texto em vetor de caracteres
        Array.Reverse(letras);                        // inverte a ordem do vetor
        return new string(letras);                    // monta um novo texto a partir do vetor
    }

    public static bool EhPalindromo(string texto)
    {
        string limpo = new string(                    // monta um texto só com letras e números, em minúsculas
            texto.ToLower().Where(char.IsLetterOrDigit).ToArray());
        return limpo == Inverter(limpo);              // reutiliza a função Inverter: igual ao contrário = palíndromo
    }

    // SOBRECARGA: mesmo nome "Area", parâmetros diferentes
    public static double Area(double raio) => Math.PI * raio * raio;       // círculo
    public static double Area(double b, double h) => b * h;                // retângulo

    // PARÂMETRO OPCIONAL: se não informar o percentual, usa 10
    public static double AplicarDesconto(double preco, double percentual = 10)
    {
        return preco - preco * percentual / 100;      // preço menos o valor do desconto
    }
}

// Objetivo: mostrar o MAIOR de três números. Este código tem um defeito de lógica.
int a = 5, b = 9, c = 7;       // troque estes valores para os casos de teste
int maior = a;                 // começa supondo que "a" é o maior

if (b > maior) maior = b;      // b é maior que o maior atual?

  1. Coloque um ponto de interrupção (F9) na linha int maior = a; e execute com F5.
  2. Avance com F10 e acompanhe a, b, c e maior nas janelas Locais e Inspeção.
  3. Com (9, 5, 7), observe o valor de maior após cada if. Em que momento ele fica errado? Por quê?

Ver o defeito

A linha if (c > b) maior = c; compara c com b e não com maior. Com (9, 5, 7): maior vale 9, c > b (7 > 5) é verdadeiro e maior passa a ser 7 (errado). Correção: if (c > maior) maior = c;.

Projeto 8 · Controle de Gastos (projeto integrador do módulo)

Objetivo: reunir tudo: menu, decisão, repetição, listas, funções reutilizáveis, validação e formatação. Repare no padrão de modularização: o código principal só decide o que chamar; cada função faz uma coisa.

Console.OutputEncoding = System.Text.Encoding.UTF8;

var descricoes = new List<string>();                  // lista PARALELA: descricoes[i] combina com valores[i]
var valores = new List<decimal>();                    // decimal: o tipo certo para dinheiro
int opcao;

do
{
    MostrarMenu();
    opcao = LerInteiro("Escolha: ");

    switch (opcao)
    {
        case 1: Adicionar(descricoes, valores); break;
        case 2: Listar(descricoes, valores); break;
        case 3: MostrarResumo(descricoes, valores); break;
        case 4: Remover(descricoes, valores); break;
        case 0: Console.WriteLine("Até logo!"); break;
        default: Console.WriteLine("Opção inválida."); break;
    }
} while (opcao != 0);

// ---------- FUNÇÕES (ficam depois do código principal; "static" = não usam variáveis de fora) ----------

static void MostrarMenu()                             // void: só mostra, não devolve nada
{
    Console.WriteLine("\n=== CONTROLE DE GASTOS ===");
    Console.WriteLine("1 - Adicionar gasto");
    Console.WriteLine("2 - Listar gastos");
    Console.WriteLine("3 - Resumo");
    Console.WriteLine("4 - Remover gasto");
    Console.WriteLine("0 - Sair");
}

static int LerInteiro(string mensagem)                // função reutilizável: lê um inteiro válido
{
    int valor;
    Console.Write(mensagem);
    while (!int.TryParse(Console.ReadLine(), out valor))   // repete até digitar um inteiro
    {
        Console.Write("Valor inválido. " + mensagem);
    }
    return valor;                                     // devolve o número lido
}

static decimal LerDecimal(string mensagem)            // mesma ideia para valores em dinheiro
{
    decimal valor;
    Console.Write(mensagem);
    while (!decimal.TryParse(Console.ReadLine(), out valor))
    {
        Console.Write("Valor inválido. " + mensagem);
    }
    return valor;
}

static void Adicionar(List<string> descricoes, List<decimal> valores)   // listas passadas como PARÂMETROS
{
    Console.Write("Descrição: ");
    string descricao = (Console.ReadLine() ?? "").Trim();
    if (descricao == "")                              // validação
    {
        Console.WriteLine("A descrição não pode ficar vazia.");
        return;                                       // return em função void: sai da função
    }

    decimal valor = LerDecimal("Valor (R$): ");
    if (valor <= 0)                                   // validação de regra
    {
        Console.WriteLine("O valor deve ser maior que zero.");
        return;
    }

    descricoes.Add(descricao);                        // Add coloca no fim da lista
    valores.Add(valor);                               // as duas listas crescem JUNTAS para manter a correspondência
    Console.WriteLine("Gasto registrado!");
}

static void Listar(List<string> descricoes, List<decimal> valores)
{
    if (valores.Count == 0)                           // Count = quantidade de itens da lista
    {
        Console.WriteLine("Nenhum gasto registrado.");
        return;
    }

    Console.WriteLine();
    for (int i = 0; i < valores.Count; i++)           // percorre pelo índice para usar as duas listas
    {
        Console.WriteLine($"{i + 1,2}. {descricoes[i],-25} {valores[i],12:C2}");   // alinha em colunas; C2 = moeda
    }
}

static void MostrarResumo(List<string> descricoes, List<decimal> valores)
{
    if (valores.Count == 0)
    {
        Console.WriteLine("Nenhum gasto registrado.");
        return;
    }

    decimal total = valores.Sum();                    // LINQ: soma todos os valores
    decimal media = total / valores.Count;            // média = total / quantidade
    decimal maior = valores.Max();                    // LINQ: maior valor
    int indice = valores.IndexOf(maior);              // posição do maior, para achar a descrição correspondente

    Console.WriteLine($"\nTotal gasto:   {total:C2}");
    Console.WriteLine($"Média por gasto: {media:C2}");
    Console.WriteLine($"Maior gasto:   {descricoes[indice]} ({maior:C2})");
}

static void Remover(List<string> descricoes, List<decimal> valores)
{
    if (valores.Count == 0)
    {
        Console.WriteLine("Nenhum gasto para remover.");
        return;
    }

    Listar(descricoes, valores);                      // reutiliza a função Listar
    int numero = LerInteiro("Número do gasto a remover (0 cancela): ");

    if (numero == 0) return;                          // cancelou
    if (numero < 1 || numero > valores.Count)         // índice válido?
    {
        Console.WriteLine("Número inexistente.");
        return;
    }

    descricoes.RemoveAt(numero - 1);                  // RemoveAt usa o ÍNDICE (começa em 0); por isso numero - 1
    valores.RemoveAt(numero - 1);                     // remove das DUAS listas, mantendo-as alinhadas
    Console.WriteLine("Gasto removido.");
}
