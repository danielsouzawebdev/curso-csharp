3. Exercícios

  1. Análise de requisitos. Um laboratório tem computadores com 4 GB de RAM, HDD de 500 GB (com 80 GB livres) e Windows 10 64 bits. Eles atendem ao mínimo do Visual Studio? E ao recomendado? Que ações (e prioridades) você recomendaria, em ordem de custo-benefício?
  2. Planejamento para 20 máquinas. A instalação baixa cerca de 6 GB por máquina. Calcule o total e o tempo se a internet for de 100 Mbps compartilhada. Proponha uma alternativa (layout offline, instalação em horários diferentes).
  3. Commits. Reescreva estas mensagens ruins de forma clara: “mudei umas coisas”, “final”, “agora vai”, “arrumei o bug”.
  4. .gitignore. Explique por que bin/ e obj/ não devem ser versionadas e o que aconteceria se um arquivo com senha fosse enviado ao GitHub (e como corrigir: revogar a senha, não apenas apagar o arquivo).
  5. Conflito de merge (em dupla). (a) Duas pessoas clonam o mesmo repositório. (b) Cada uma altera a mesma linha do README.md e faz commit. (c) A primeira envia (push); a segunda tenta push e recebe erro. (d) A segunda faz git pull e verá marcas de conflito no arquivo. (e) Escolhem o texto final, apagam as marcas, git add, git commit e git push. Registre cada etapa.
  6. Pull request. Crie uma branch, faça uma alteração no README, envie a branch e abra um Pull Request no GitHub para o colega revisar e aprovar.
  7. Diagnóstico. Provoque de propósito: pare o MySQL do Laragon e rode o programa de verificação. Que mensagem aparece? Qual a causa e a solução?
  8. Reprodutibilidade. Escreva, no README, o passo a passo para que alguém sem experiência instale seu ambiente. Peça a um colega para executar e anote o que faltou.

5. Solução de problemas

SintomaCausa provávelO que fazer
Instalador do Visual Studio pede mais espaço ou falhaDisco cheio ou unidade erradaLiberar espaço, escolher outra unidade em “Locais de instalação”, marcar menos componentes
Instalador não baixaSem internet, proxy ou antivírus bloqueandoTestar a conexão, desativar o proxy, falar com o responsável pela rede
Modelo “Windows Forms” não apareceCarga de trabalho não instaladaInstaller → Modificar → marcar “Desenvolvimento para desktop com .NET”
dotnet não é reconhecidoSDK ausente ou terminal aberto antes da instalaçãoFechar e reabrir o terminal; reparar o Visual Studio
“fatal: not a git repository”Comando executado fora da pasta do projetoEntrar na pasta certa (cd) ou rodar git init
“Authentication failed” no pushCredencial expirada ou incorretaRefazer o login no navegador (Git Credential Manager) ou usar token pessoal
“failed to push some refs” / “rejected”O remoto tem commits que você não temgit pull e depois git push
Pastas bin e obj foram enviadas ao GitHub.gitignore ausente na hora do primeiro commitCriar o .gitignore e remover do controle com git rm -r --cached bin obj, depois commit
MySQL do Laragon não iniciaPorta 3306 ocupada ou outro MySQL instaladoDescobrir o processo (netstat), encerrar o outro serviço ou mudar a porta nas configurações do Laragon
Janela de licença do LaragonVersão que solicita licençaLer os termos no site oficial; confirmar com o professor; alternativa: outro MySQL/MariaDB local
“Access denied for user 'root'”Senha do banco diferente da string de conexãoConferir a senha no HeidiSQL e ajustar o texto de conexão
