Preparação do Ambiente de Desenvolvimento

Antes de programar, é preciso ter as ferramentas certas, instaladas e configuradas do jeito certo. Neste módulo você reconhece as ferramentas do desenvolvedor (IDE, SDK, repositório, banco de dados), confere os requisitos mínimos do seu computador, instala e configura tudo, e prova que o ambiente funciona com um programa de verificação. Também aprende o básico de controle de versão com Git e GitHub. O módulo é independente: não exige conhecimento prévio de programação.

💡 Versões mudam. Os números e nomes de menus deste módulo foram conferidos na época da escrita (Visual Studio 2026 e .NET 10). Antes de instalar, confirme nas páginas oficiais da Microsoft, do Git, do GitHub e do Laragon; o professor deve validar o roteiro em uma máquina do laboratório.

Objetivos de aprendizagem

  • Explicar a função de cada ferramenta: IDE, SDK, compilador, gerenciador de pacotes, controle de versão, repositório remoto e SGBD.
  • Comparar os requisitos mínimos e recomendados com o hardware e o software disponíveis.
  • Instalar e configurar o Visual Studio, o SDK do .NET, o Git e o Laragon, seguindo parâmetros de configuração.
  • Criar e executar o primeiro projeto (Console e Windows Forms) e verificar o ambiente com código C#.
  • Usar Git e GitHub: repositório local e remoto, commit, push, pull, branch e merge.
  • Documentar o ambiente para que outra pessoa consiga reproduzi-lo.
  • Diagnosticar problemas comuns de instalação.

Foco do módulo

Núcleo obrigatório
  • Reconhecer o papel de IDE, SDK, compilador, Git, repositório remoto e SGBD.
  • Criar e executar projetos Console e Windows Forms.
  • Configurar a identidade Git com --local em computadores compartilhados.
  • Fazer o primeiro ciclo status → add → commit → push e encerrar a sessão com segurança.
Aprofundamento
  • Branch e merge como introdução ao trabalho colaborativo.
  • Laragon/MySQL como preparação para o módulo de banco de dados.
  • Documentação do ambiente para permitir reprodução em outra máquina.
✅ Critério de conclusãoVocê concluiu o módulo quando consegue criar um projeto novo, executá-lo, versioná-lo e enviá-lo ao GitHub sem deixar credenciais pessoais na máquina do laboratório.
🔗 Conexão com a trilhaNo Módulo 1, o ambiente deixa de ser o foco: você passa a resolver problemas com algoritmos e C# em projetos de console.

Pré-requisitos

  • Computador com Windows (o Windows Forms só roda no Windows) e permissão de administrador, ou acesso às máquinas do laboratório.
  • Conexão com a internet e um e-mail para criar a conta no GitHub.
  • Cerca de 30 a 50 GB livres de disco para a instalação completa.
