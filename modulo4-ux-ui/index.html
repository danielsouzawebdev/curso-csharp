UX e UI em aplicações Windows Forms

Neste módulo você aprende a projetar telas que as pessoas conseguem usar com rapidez, sem erro e sem frustração, e a aplicar esses princípios em C#. Ele é independente: não precisa dos outros módulos, apenas de noções básicas de Windows Forms.

Objetivos de aprendizagem

  • Diferenciar UX, UI, usabilidade e acessibilidade.
  • Avaliar uma tela usando as 10 heurísticas de Nielsen.
  • Aplicar princípios visuais: proximidade, alinhamento, hierarquia, contraste e consistência.
  • Escolher o controle certo para cada tipo de dado.
  • Programar validação, feedback e confirmações em C#.
  • Reutilizar o visual do sistema em uma classe de tema.
  • Testar a usabilidade com usuários reais e registrar os problemas.

Foco do módulo

Núcleo obrigatório
  • Distinguir UX de UI e tomar decisões pensando no usuário.
  • Organizar formulários com hierarquia visual, alinhamento, espaçamento e consistência.
  • Escolher controles adequados e fornecer feedback de validação e confirmação.
  • Realizar um teste simples de usabilidade e registrar problemas observados.
Aprofundamento
  • Aplicar as heurísticas de Nielsen como instrumento de análise.
  • Criar uma classe de tema para reutilizar decisões visuais.
✅ Critério de conclusãoVocê concluiu o módulo quando consegue justificar por que uma tela é fácil ou difícil de usar e melhorar um formulário com base em evidências observáveis.
🔗 Conexão com a trilhaNo Módulo 5, a aplicação deixa de manter dados apenas em memória e passa a persistir informações em banco.

Conhecimentos do plano de curso atendidos

Fundamentos de User Experience (UX) · Design UI e UX · Reutilização de código · Documentação de código · Identificação de erros conforme o requisito.

Pré-requisitos

  • Visual Studio com a carga Desenvolvimento para desktop com .NET (.NET 6 ou superior).
  • Saber criar um projeto Windows Forms, adicionar controles e criar eventos de clique.
  • Saber criar uma classe simples em C#.
