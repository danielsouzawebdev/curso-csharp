Prática guiada · Cadastro de Clientes

🧭 Como executar esta práticaDigite o código, execute a cada etapa e compare o comportamento com o resultado descrito. Se houver erro, leia a mensagem antes de alterar o código e use o depurador quando indicado.

Meta: construir uma tela de cadastro com boa usabilidade: validação clara, feedback, atalhos, confirmação de exclusão e visual consistente. Faça as etapas na ordem e digite o código lendo cada comentário.

💡 O código desta prática foi escrito para .NET 6 ou superior. Se aparecer erro de namespace, use o mesmo nome do seu projeto (CadastroClientes) no início de cada arquivo.

Etapa 0 · Diagnóstico: o que há de errado na tela “antes”?

Imagine uma tela com: título “Form1”, campos sem rótulo claro, todos os controles com tamanhos diferentes, botões “OK” e “Button2”, ordem de Tab bagunçada, mensagem “Erro!”, exclusão sem confirmação e nenhuma indicação de campos obrigatórios. Anote no caderno quais heurísticas e princípios ela viola (use a Teoria). Ao final do módulo, compare com sua lista.

Crie o projeto e configure o formulário

Visual Studio → Criar um projeto → Aplicativo do Windows Forms (C#) → nome CadastroClientes. Renomeie Form1.cs para FrmClientes.cs (clique direito → Renomear; confirme a atualização das referências). No designer, selecione o formulário e defina:

Planeje o layout

Use uma grade simples: margem de 16 px nas bordas, rótulo acima do campo, 8 px entre rótulo e campo e 16 px entre um campo e o próximo. Todos os campos com o mesmo Left (ex.: 16) e a mesma largura (ex.: 320). Organização:

  • Parte de cima: GroupBox com os dados.
  • Meio: linha de botões (Salvar à esquerda como principal, Limpar ao lado, Excluir afastado).
  • Embaixo: grade de clientes e a barra de status.

Defina a ordem de Tab e os botões padrão

Menu Exibir → Ordem de Tabulação: clique nos controles na ordem em que o usuário preenche (nome → telefone → e-mail → nascimento → tipo → ofertas → salvar). Depois, nas propriedades do formulário, defina AcceptButton = btnSalvar e CancelButton = btnLimpar. Teste com F5 só usando o teclado.

Crie o modelo Cliente

Clique direito no projeto → Adicionar → Classe → Cliente.cs.

namespace CadastroClientes;                    // agrupa as classes do projeto; deve ter o nome do projeto

public class Cliente                           // modelo: guarda os dados de UM cliente
{
    public string Nome { get; set; } = "";     // nome completo; = "" evita valor nulo
    public string Telefone { get; set; } = ""; // telefone já formatado pela máscara
    public string Email { get; set; } = "";    // e-mail digitado
    public DateTime Nascimento { get; set; }   // DateTime guarda data e hora; usaremos só a data
    public string Tipo { get; set; } = "";     // "Pessoa Física" ou "Pessoa Jurídica"
    public bool ReceberOfertas { get; set; }   // bool: true = marcou o CheckBox
}

Crie a classe Tema (reutilização de código)

Em vez de repetir cores e estilos em cada tela, centralizamos tudo em um único lugar. Se a cor mudar, altera-se só aqui. Adicione Tema.cs:

namespace CadastroClientes;                                    // mesmo namespace do projeto

public static class Tema                                       // static: usamos direto como Tema.Primaria, sem new
{
    // readonly: o valor é definido uma vez e não muda mais.
    // Color.FromArgb(R, G, B) cria uma cor pelos componentes vermelho, verde e azul (0 a 255).
    public static readonly Color Primaria = Color.FromArgb(15, 118, 110);  // verde-azulado: ação principal
    public static readonly Color Perigo   = Color.FromArgb(185, 28, 28);   // vermelho: ação destrutiva
    public static readonly Color Fundo    = Color.FromArgb(244, 247, 246); // fundo claro do formulário
    public static readonly Color Texto    = Color.FromArgb(31, 45, 43);    // texto escuro: bom contraste com o fundo

    public static void BotaoPrincipal(Button b)                // aplica o estilo do botão de ação principal
    {
        Estilizar(b, Primaria, Color.White);                   // fundo colorido e texto branco
    }

    public static void BotaoPerigo(Button b)                   // aplica o estilo de ações destrutivas
    {
        Estilizar(b, Perigo, Color.White);                     // vermelho com texto branco
    }

    public static void BotaoNeutro(Button b)                   // botões secundários, de menor destaque
    {
        Estilizar(b, Color.White, Texto);                      // fundo branco e texto escuro
        b.FlatAppearance.BorderColor = Color.Gray;             // borda cinza para o botão não "sumir" no fundo
    }

    private static void Estilizar(Button b, Color fundo, Color texto) // método auxiliar: só a classe usa (private)
    {
        b.FlatStyle = FlatStyle.Flat;                          // visual plano e moderno (sem o 3D antigo)
        b.FlatAppearance.BorderSize = 1;                       // borda fina de 1 pixel
        b.BackColor = fundo;                                   // cor de fundo recebida por parâmetro
        b.ForeColor = texto;                                   // cor do texto recebida por parâmetro
        b.Cursor = Cursors.Hand;                               // cursor de "mãozinha" indica que é clicável
        b.Height = 34;                                         // altura padrão para todos os botões
    }
}

Programe o carregamento do formulário

Abra FrmClientes.cs (tecla F7). Dê clique duplo no formulário no designer para criar o evento Load. Antes dele, declare os campos da classe. Em using, acrescente using System.ComponentModel; e using System.Net.Mail; no topo.

// Campos da classe: existem enquanto o formulário estiver aberto.
private readonly BindingList<Cliente> clientes = new();   // lista que avisa a grade quando muda (atualiza sozinha)
private readonly ErrorProvider erros = new();             // mostra o ícone de erro ao lado do campo
private readonly ToolTip dicas = new();                   // balão de ajuda que aparece ao passar o mouse

private void FrmClientes_Load(object sender, EventArgs e) // roda uma vez, quando o formulário abre
{
    BackColor = Tema.Fundo;                               // aplica a cor de fundo do tema ao formulário
    Tema.BotaoPrincipal(btnSalvar);                       // Salvar = destaque (ação principal)
    Tema.BotaoNeutro(btnLimpar);                          // Limpar = discreto (ação secundária)
    Tema.BotaoPerigo(btnExcluir);                         // Excluir = vermelho (ação perigosa)

    cmbTipo.Items.AddRange(new object[] { "Pessoa Física", "Pessoa Jurídica" }); // opções permitidas
    cmbTipo.SelectedIndex = 0;                            // já deixa a primeira opção selecionada (menos cliques)

    dtpNascimento.MaxDate = DateTime.Today;               // impede escolher uma data de nascimento no futuro
    dgvClientes.DataSource = clientes;                    // liga a grade à lista: o que entrar na lista aparece na tela
    btnExcluir.Enabled = false;                           // sem cliente selecionado, excluir não faz sentido (prevenção de erro)

    dicas.SetToolTip(mskTelefone, "Informe DDD e número. Ex.: (11) 91234-5678"); // dica de preenchimento
    dicas.SetToolTip(txtEmail, "Ex.: nome@dominio.com");  // dica com exemplo de e-mail

    MostrarStatus("Pronto. Preencha os dados e pressione Enter para salvar.", false); // orienta o usuário
    txtNome.Focus();                                      // cursor já no primeiro campo
}

Crie o método de feedback na barra de status

Esse método será usado em todo o formulário para falar com o usuário.

private void MostrarStatus(string mensagem, bool ehErro)  // mensagem: o texto; ehErro: define a cor
{
    tslStatus.Text = mensagem;                            // escreve o texto na barra de status
    tslStatus.ForeColor = ehErro ? Tema.Perigo : Tema.Texto; // ? : é um if curto: erro = vermelho, normal = texto escuro
}

Programe a validação com ErrorProvider

Validamos ao salvar e mostramos o erro ao lado do campo, com mensagem que explica como corrigir. O foco vai para o primeiro campo com problema.

private bool Validar()                                    // devolve true se está tudo certo, false se há erro
{
    erros.Clear();                                        // apaga os ícones de erro da tentativa anterior
    Control? primeiroErro = null;                         // guarda o primeiro campo com erro (para dar foco); null = nenhum

    if (txtNome.Text.Trim().Length < 3)                   // Trim remove espaços das pontas; exige pelo menos 3 letras
    {
        erros.SetError(txtNome, "Informe o nome completo (mínimo de 3 letras)."); // ícone + mensagem ao lado do campo
        primeiroErro ??= txtNome;                         // ??= só atribui se ainda for null (mantém o PRIMEIRO erro)
    }

    if (!mskTelefone.MaskCompleted)                       // MaskCompleted: true só se todos os dígitos da máscara foram preenchidos
    {
        erros.SetError(mskTelefone, "Complete o telefone com DDD. Ex.: (11) 91234-5678.");
        primeiroErro ??= mskTelefone;
    }

    if (!EmailValido(txtEmail.Text))                      // usa o método auxiliar abaixo
    {
        erros.SetError(txtEmail, "Informe um e-mail válido. Ex.: nome@dominio.com.");
        primeiroErro ??= txtEmail;
    }

    primeiroErro?.Focus();                                // ?. só executa se não for null: leva o cursor ao 1º erro
    return primeiroErro == null;                          // se não houve nenhum erro, a validação passou
}

private static bool EmailValido(string email)             // static: não usa nenhum dado do formulário
{
    try                                                   // tenta executar; se der exceção, cai no catch
    {
        var endereco = new MailAddress(email);            // a classe MailAddress verifica o formato; lança erro se inválido
        return endereco.Address == email.Trim();          // garante que não veio "Nome <email>" ou texto extra
    }
    catch                                                 // qualquer erro de formato (inclusive texto vazio)
    {
        return false;                                     // e-mail considerado inválido
    }
}

Programe Salvar, Limpar e Excluir

Dê clique duplo em cada botão no designer para criar os eventos e escreva:

private void btnSalvar_Click(object sender, EventArgs e)  // clique em Salvar (ou tecla Enter, pois é o AcceptButton)
{
    if (!Validar())                                       // se a validação falhar...
    {
        MostrarStatus("Corrija os campos marcados em vermelho.", true); // ...avisa o que fazer
        return;                                           // ...e interrompe: nada é salvo
    }

    clientes.Add(new Cliente                              // cria um objeto Cliente e coloca na lista
    {
        Nome = txtNome.Text.Trim(),                       // guarda o nome sem espaços sobrando
        Telefone = mskTelefone.Text,                      // telefone já com a máscara aplicada
        Email = txtEmail.Text.Trim(),                     // e-mail sem espaços sobrando
        Nascimento = dtpNascimento.Value.Date,            // .Date descarta a hora, mantém só o dia
        Tipo = cmbTipo.Text,                              // texto da opção escolhida no ComboBox
        ReceberOfertas = chkOfertas.Checked               // true se o CheckBox está marcado
    });

    MostrarStatus($"Cliente {txtNome.Text.Trim()} salvo com sucesso!", false); // feedback de sucesso (ANTES de limpar!)
    LimparCampos();                                       // deixa a tela pronta para o próximo cadastro
}

private void btnLimpar_Click(object sender, EventArgs e)  // clique em Limpar (ou tecla Esc, pois é o CancelButton)
{
    LimparCampos();                                       // reaproveita o método (evita repetir código)
    MostrarStatus("Formulário limpo.", false);            // informa o que aconteceu
}

private void LimparCampos()                               // método reutilizado por Salvar e Limpar
{
    erros.Clear();                                        // remove os ícones de erro
    txtNome.Clear();                                      // esvazia o nome
    mskTelefone.Clear();                                  // esvazia o telefone (mantém a máscara)
    txtEmail.Clear();                                     // esvazia o e-mail
    dtpNascimento.Value = DateTime.Today;                 // volta a data para hoje
    cmbTipo.SelectedIndex = 0;                            // volta para a primeira opção
    chkOfertas.Checked = false;                           // desmarca o CheckBox
    txtNome.Focus();                                      // cursor volta ao primeiro campo
}

private void dgvClientes_SelectionChanged(object sender, EventArgs e) // dispara quando a seleção da grade muda
{
    btnExcluir.Enabled = dgvClientes.CurrentRow != null;  // habilita Excluir só se há uma linha selecionada
}

private void btnExcluir_Click(object sender, EventArgs e)
{
    var cliente = dgvClientes.CurrentRow?.DataBoundItem as Cliente; // pega o objeto da linha; "as" converte e devolve null se falhar
    if (cliente == null) return;                          // segurança: sem cliente, não faz nada

    var resposta = MessageBox.Show(                       // abre a janela de confirmação
        $"Excluir o cliente \"{cliente.Nome}\"? Esta ação não pode ser desfeita.", // mensagem clara e específica
        "Confirmar exclusão",                             // título da janela
        MessageBoxButtons.YesNo,                          // botões Sim e Não
        MessageBoxIcon.Warning,                           // ícone de alerta
        MessageBoxDefaultButton.Button2);                 // botão padrão = "Não": o caminho seguro

    if (resposta == DialogResult.Yes)                     // só exclui se o usuário confirmou
    {
        clientes.Remove(cliente);                         // remove da lista; a grade atualiza sozinha
        MostrarStatus("Cliente excluído.", false);        // feedback da ação
    }
}

Conecte os eventos e rode

Confira no designer (ícone ⚡ nas propriedades) que o evento SelectionChanged da grade aponta para dgvClientes_SelectionChanged. Rode com F5 e teste: salvar com campos vazios (veja os ícones e o foco), salvar com dados corretos, usar só o teclado (Tab, Enter, Esc) e excluir confirmando e cancelando.
