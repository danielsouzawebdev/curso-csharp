Programação de Aplicativos em C#

Material autoinstrucional para a UC de Programação de Aplicativos, com progressão da lógica de programação ao desenvolvimento de aplicações desktop em C#, Windows Forms, MySQL, testes, Git/GitHub e projeto integrador. O aluno estuda a teoria, executa práticas guiadas e valida sua aprendizagem em cada módulo.

Começar pelo Módulo 0 →Ver todos os módulos
🎯 Como estudar nesta UCCompreender → Digitar → Executar → Testar → Depurar → Registrar no Git. Evite apenas copiar e colar os exemplos. O objetivo é entender o comportamento do código e conseguir explicar por que ele funciona.

Como usar este material

  1. Siga a trilha sugerida abaixo (ou escolha um módulo se já domina os anteriores: cada módulo lista seus pré-requisitos).
  2. Em cada módulo: leia a Teoria, faça a Prática digitando o código (não copie e cole) e resolva a Avaliação.
  3. Guarde seus projetos em um repositório Git e faça commits ao final de cada etapa.
  4. Quando travar, leia a seção de solução de problemas do módulo e a mensagem de erro com calma.

Trilha de módulos

Módulo 0 · Iniciante

Ambiente e Ferramentas

Instalar e configurar Visual Studio, SDK .NET, Git, GitHub e Laragon; conferir requisitos; verificar o ambiente.

⏱ ≈ 6h30 · Pré-requisito: Nenhum

Módulo 1 · Iniciante

Lógica Estruturada em C#

Algoritmos, variáveis, decisão, repetição, vetores, funções, erros e depuração, com 8 projetos de console.

⏱ ≈ 9h30 · Pré-requisito: Módulo 0

Módulo 2 · Intermediário

Programação Orientada a Objetos

Classes, encapsulamento, herança, polimorfismo, abstração, interfaces e composição, com 8 projetos e mini loja.

⏱ ≈ 12h · Pré-requisito: Módulos 0 e 1

Módulo 3 · Intermediário

Windows Forms

Designer, controles, eventos, layout, validação, dados, vários formulários, async e publicação, com 10 projetos.

⏱ ≈ 16h30 · Pré-requisito: Módulos 0 a 2

Módulo 4 · Intermediário

UX e UI

Heurísticas de usabilidade, princípios visuais, escolha de controles e teste de usabilidade, com um cadastro de clientes.

⏱ ≈ 5h30 · Pré-requisito: Módulo 3

Módulo 5 · Intermediário

Banco de Dados com Laragon

Modelo relacional, SQL, MySQL, ADO.NET, CRUD, camadas, transações e segurança (SQL Injection).

⏱ ≈ 7h30 · Pré-requisito: Módulos 2 e 3

Módulo 6 · Avançado

Qualidade do Código

Padrões, documentação XML, refatoração, otimização, depuração, rastreabilidade e testes unitários com xUnit.

⏱ ≈ 7h30 · Pré-requisito: Módulos 2 e 3

Módulo 7 · Avançado

Gestão da Qualidade

Qualidade total, ferramentas da qualidade, indicadores, registro e melhoria contínua (PDCA).

⏱ ≈ 7h30 · Pré-requisito: Módulo 6 (recomendado)

Módulo 8 · Avançado

Projeto Integrador

Sistema completo em equipe (Biblioteca Escolar): requisitos, camadas, banco, testes, Git, qualidade e apresentação.

⏱ 5 a 6 semanas · Pré-requisito: Módulos 3 a 7

Estimativa de tempo total dos módulos 0 a 7: cerca de 72 horas, mais as 5 a 6 semanas do projeto integrador. Os tempos são sugestões e variam conforme a turma.
