Banco de Dados com C#, MySQL e Laragon

Até aqui, tudo o que o programa guardava desaparecia ao fechá-lo. Neste módulo você aprende a persistir dados em um banco relacional e a construir um CRUD completo em Windows Forms, de forma organizada e segura. O módulo é independente: basta saber Windows Forms e criar classes simples.

Objetivos de aprendizagem

  • Explicar o que são banco de dados, tabelas, chaves e relacionamentos.
  • Escrever comandos SQL: CREATE, INSERT, SELECT, UPDATE, DELETE e JOIN.
  • Instalar e usar o Laragon (MySQL/MariaDB) e o HeidiSQL.
  • Conectar o C# ao banco com MySqlConnector (ADO.NET).
  • Organizar o código em camadas: modelo, acesso a dados (DAO) e formulário.
  • Evitar SQL Injection usando parâmetros.
  • Tratar erros do banco e mostrar mensagens compreensíveis.

Foco do módulo

Núcleo obrigatório
  • Compreender tabela, linha, coluna, chave primária, chave estrangeira e relacionamento.
  • Executar SQL básico: INSERT, SELECT, UPDATE, DELETE e JOIN.
  • Conectar C# ao MySQL com MySqlConnector e comandos parametrizados.
  • Implementar CRUD separando acesso a dados da interface.
Aprofundamento
  • Transações e tratamento de concorrência para operações que precisam ser atômicas.
  • Usuário de banco com menor privilégio e configuração externa de credenciais.
✅ Critério de conclusãoVocê concluiu o módulo quando consegue salvar, listar, editar, excluir e buscar registros a partir de uma aplicação C# sem concatenar dados do usuário no SQL.
🔗 Conexão com a trilhaNo Módulo 6, você aprenderá a provar que o código atende requisitos, localizar defeitos e melhorar sua estrutura.

Conhecimentos do plano de curso atendidos

Conexão com banco de dados · Linguagem orientada a objetos · Técnicas de programação · Reutilização de código · Depuração · Documentação de código.

Pré-requisitos

  • Visual Studio com Desenvolvimento para desktop com .NET (.NET 6 ou superior).
  • Windows Forms básico (controles, eventos) e criação de classes.
  • Noção de List<T> e try/catch.
  • Computador Windows (o Laragon roda no Windows).
