Prática guiada · Controle de Estoque

🧭 Como executar esta práticaDigite o código, execute a cada etapa e compare o comportamento com o resultado descrito. Se houver erro, leia a mensagem antes de alterar o código e use o depurador quando indicado.

Meta: criar um sistema com dois relacionamentos (categorias e produtos) que permite cadastrar, listar, buscar, editar e excluir produtos, gravando tudo no MySQL do Laragon. Faça as etapas em ordem e digite o código lendo cada comentário.

💡 Os códigos valem para .NET 6 ou superior (namespace ControleEstoque; deve ter o nome do seu projeto). Cada arquivo de código usa using MySqlConnector; quando acessa o banco.

Instale e inicie o Laragon

Baixe o Laragon (versão Full) no site oficial e instale. Abra o programa e clique em Iniciar tudo. Confira se o MySQL (ou MariaDB) aparece em execução. Se o Windows pedir permissão de firewall, permita para redes privadas.

Licença: versões recentes do Laragon podem exibir avisos pedindo chave de licença. Leia os termos no site oficial; o professor deve confirmar se o uso na escola está de acordo com eles. Para os exercícios deste módulo, qualquer servidor MySQL ou MariaDB local funciona (basta ajustar a connection string).

Abra o HeidiSQL

No Laragon, clique em Banco de dados. O HeidiSQL abre com uma sessão já configurada (ou crie uma: tipo MySQL, host 127.0.0.1, usuário root, senha vazia, porta 3306) e clique em Abrir. Se conectar, você verá bancos como mysql e information_schema.

Crie o banco, as tabelas e os dados

No HeidiSQL, abra uma aba de consulta (Ctrl+T), cole o script abaixo e execute tudo com F9. Atualize a lista (F5) e confira o banco estoque. Guarde o script em um arquivo estoque.sql: ele é um dos entregáveis.

-- Cria o banco de dados "estoque" (só se ainda não existir), com suporte a acentos
CREATE DATABASE IF NOT EXISTS estoque CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;

-- Diz ao MySQL que os próximos comandos valem para o banco "estoque"
USE estoque;

-- Tabela de categorias (lado "1" do relacionamento 1:N)
CREATE TABLE categorias (
    id   INT AUTO_INCREMENT PRIMARY KEY,   -- número gerado automaticamente; identifica a categoria
    nome VARCHAR(60) NOT NULL UNIQUE       -- obrigatório e sem repetição
);

-- Tabela de produtos (lado "N" do relacionamento)
CREATE TABLE produtos (
    id           INT AUTO_INCREMENT PRIMARY KEY,         -- identificador único do produto
    nome         VARCHAR(100) NOT NULL UNIQUE,           -- nome obrigatório e único
    preco        DECIMAL(10,2) NOT NULL DEFAULT 0,       -- dinheiro com 2 casas decimais
    quantidade   INT NOT NULL DEFAULT 0,                 -- quantidade em estoque
    categoria_id INT NOT NULL,                           -- guarda o id da categoria (chave estrangeira)
    criado_em    DATETIME DEFAULT CURRENT_TIMESTAMP,     -- data e hora preenchidas automaticamente
    CONSTRAINT fk_produto_categoria                      -- nome da regra (útil em mensagens de erro)
        FOREIGN KEY (categoria_id) REFERENCES categorias(id) -- só aceita ids que existem em categorias
);

INSERT INTO produtos (nome, preco, quantidade, categoria_id) VALUES

Treine SQL antes de programar

Execute uma consulta por vez (selecione o comando e pressione Ctrl+Enter) e observe o resultado. Entender o SQL antes de usá-lo no C# facilita muito encontrar erros depois.

-- 1) Todos os produtos
SELECT * FROM produtos;

-- 2) Só nome e preço, do mais caro ao mais barato
SELECT nome, preco FROM produtos ORDER BY preco DESC;

-- 3) Produtos com menos de 30 unidades
SELECT nome, quantidade FROM produtos WHERE quantidade < 30;

-- 4) Buscar pelo pedaço do nome (% = qualquer texto)
SELECT * FROM produtos WHERE nome LIKE '%arroz%';

-- 5) JOIN: mostra o NOME da categoria em vez do número
SELECT p.nome AS produto, c.nome AS categoria, p.preco
FROM produtos p
INNER JOIN categorias c ON c.id = p.categoria_id;

-- 6) Valor total em estoque (preço x quantidade de cada produto, somado)
SELECT SUM(preco * quantidade) AS valor_total FROM produtos;

Crie a classe de conexão

Clique direito no projeto → Adicionar → Classe → Conexao.cs. Ela é o único lugar que conhece a connection string.

using MySqlConnector;                                              // traz as classes do driver do MySQL

namespace ControleEstoque;

public static class Conexao                                        // static: usamos direto, sem "new"
{
    // const: valor fixo. Server = onde está o banco; Port = porta; Database = qual banco; User ID/Password = acesso.
    private const string Texto =
        "Server=localhost;Port=3306;Database=estoque;User ID=root;Password=;";
    // Se aparecer erro de SSL em ambiente local de estudo, acrescente ";SslMode=None" ao final do texto acima.

    public static MySqlConnection Criar()                          // devolve uma conexão NOVA (ainda fechada)
    {
        return new MySqlConnection(Texto);                         // cada operação cria e fecha a sua própria conexão
    }

    public static bool Testar(out string mensagem)                 // out: devolve um segundo resultado (a mensagem)
    {
        try                                                        // tenta conectar
        {
            using var con = Criar();                               // using var: fecha a conexão ao fim do método
            con.Open();                                            // abre de fato o canal com o banco
            mensagem = "Conectado ao MySQL, versão " + con.ServerVersion; // ServerVersion: versão do servidor
            return true;                                           // deu certo
        }
        catch (MySqlException ex)                                  // erro específico do MySQL
        {
            mensagem = ErroBanco.Traduzir(ex);                     // converte o erro técnico em texto amigável
            return false;                                          // falhou
        }
    }
}
🔐 Configuração didáticaO usuário root com senha vazia é usado aqui apenas para simplificar um servidor local de laboratório. Em um sistema real, crie um usuário específico, use senha forte, conceda somente as permissões necessárias e não mantenha credenciais diretamente no código-fonte.

Crie o tradutor de erros

Nova classe ErroBanco.cs. Ela transforma números de erro do MySQL em mensagens que o usuário entende (veja a tabela na Teoria).

using MySqlConnector;

namespace ControleEstoque;

public static class ErroBanco
{
    public static string Traduzir(MySqlException ex)               // recebe a exceção e devolve o texto para o usuário
    {
        return ex.Number switch                                    // switch: escolhe uma resposta conforme o número do erro
        {
            1062 => "Já existe um registro com esse valor. Use outro nome.",              // campo UNIQUE repetido
            1451 => "Não é possível excluir: existem registros vinculados a este item.",  // proteção da chave estrangeira
            1452 => "A categoria informada não existe.",                                  // FK inválida
            1045 => "Usuário ou senha do banco incorretos.",                              // login do banco negado
            1049 => "O banco de dados não foi encontrado. Execute o script estoque.sql.", // banco não criado
            _    => "Não foi possível acessar o banco. Verifique se o MySQL do Laragon está iniciado." // _ = qualquer outro caso
        };
    }
}

Crie o CategoriaDAO

DAO (Data Access Object) é a classe que sabe ler e gravar uma entidade no banco. Esta é simples: só lista categorias.

using MySqlConnector;

namespace ControleEstoque;

public class CategoriaDAO
{
    public List<Categoria> Listar()                                // devolve todas as categorias em uma lista
    {
        var lista = new List<Categoria>();                         // lista vazia que será preenchida

        using var con = Conexao.Criar();                           // cria a conexão (fecha sozinha ao sair do método)
        con.Open();                                                // abre a conexão

        using var cmd = new MySqlCommand(                          // prepara o comando SQL
            "SELECT id, nome FROM categorias ORDER BY nome", con); // ordena por nome para facilitar a escolha

        using var leitor = cmd.ExecuteReader();                    // executa e devolve um leitor das linhas
        int colId = leitor.GetOrdinal("id");                       // descobre a posição da coluna "id" (uma vez só)
        int colNome = leitor.GetOrdinal("nome");                   // posição da coluna "nome"

        while (leitor.Read())                                      // Read() avança uma linha; false quando acabam
        {
            lista.Add(new Categoria                                // cria um objeto para cada linha lida
            {
                Id = leitor.GetInt32(colId),                       // lê a coluna id como int
                Nome = leitor.GetString(colNome)                   // lê a coluna nome como string
            });
        }
        return lista;                                              // devolve todas as categorias encontradas
    }
}

Crie o ProdutoDAO (CRUD)

Esta é a classe mais importante do módulo. Leia os comentários com calma: repare que todo valor digitado vai por parâmetro e que o método Parametros evita repetir código.

using MySqlConnector;

namespace ControleEstoque;

public class ProdutoDAO
{
    // ---------- CREATE ----------
    public void Inserir(Produto p)
    {
        using var con = Conexao.Criar();                           // nova conexão
        con.Open();                                                // abre
        using var cmd = new MySqlCommand(                          // comando INSERT com parâmetros (@...)
            "INSERT INTO produtos (nome, preco, quantidade, categoria_id) " +
            "VALUES (@nome, @preco, @qtd, @cat)", con);
        Parametros(cmd, p);                                        // preenche os @ com os valores do produto
        cmd.ExecuteNonQuery();                                     // executa (INSERT não devolve linhas)
        p.Id = (int)cmd.LastInsertedId;                            // pega o id que o AUTO_INCREMENT acabou de gerar
    }

    // ---------- READ ----------
    public List<Produto> Listar(string busca)                      // busca vazia = traz todos
    {
        var lista = new List<Produto>();                           // resultado
        using var con = Conexao.Criar();
        con.Open();
        using var cmd = new MySqlCommand(
            "SELECT p.id, p.nome, p.preco, p.quantidade, p.categoria_id, c.nome AS categoria " + // colunas desejadas
            "FROM produtos p " +                                   // tabela principal (apelido p)
            "INNER JOIN categorias c ON c.id = p.categoria_id " +  // junta com a categoria pelo id
            "WHERE p.nome LIKE @busca " +                          // filtra pelo texto digitado
            "ORDER BY p.nome", con);                               // ordem alfabética
        cmd.Parameters.AddWithValue("@busca", "%" + busca + "%");  // % antes e depois = "contém o texto" (ainda como parâmetro!)

        using var leitor = cmd.ExecuteReader();
        int iId = leitor.GetOrdinal("id");                         // posições das colunas
        int iNome = leitor.GetOrdinal("nome");
        int iPreco = leitor.GetOrdinal("preco");
        int iQtd = leitor.GetOrdinal("quantidade");
        int iCatId = leitor.GetOrdinal("categoria_id");
        int iCatNome = leitor.GetOrdinal("categoria");             // o apelido "categoria" definido no SELECT

        while (leitor.Read())                                      // uma volta para cada produto encontrado
        {
            lista.Add(new Produto
            {
                Id = leitor.GetInt32(iId),                         // int
                Nome = leitor.GetString(iNome),                    // string
                Preco = leitor.GetDecimal(iPreco),                 // decimal
                Quantidade = leitor.GetInt32(iQtd),                // int
                CategoriaId = leitor.GetInt32(iCatId),             // int
                CategoriaNome = leitor.GetString(iCatNome)         // nome vindo do JOIN
            });
        }
        return lista;
    }

    // ---------- UPDATE ----------
    public void Atualizar(Produto p)
    {
        using var con = Conexao.Criar();
        con.Open();
        using var cmd = new MySqlCommand(
            "UPDATE produtos SET nome=@nome, preco=@preco, quantidade=@qtd, categoria_id=@cat " +
            "WHERE id=@id", con);                                  // WHERE id: altera SÓ este produto
        Parametros(cmd, p);                                        // mesmos parâmetros do INSERT
        cmd.Parameters.AddWithValue("@id", p.Id);                  // parâmetro extra, usado só no UPDATE
        cmd.ExecuteNonQuery();
    }

    // ---------- DELETE ----------
    public void Excluir(int id)
    {
        using var con = Conexao.Criar();
        con.Open();
        using var cmd = new MySqlCommand("DELETE FROM produtos WHERE id=@id", con); // sem WHERE apagaria tudo!
        cmd.Parameters.AddWithValue("@id", id);
        cmd.ExecuteNonQuery();
    }

    // ---------- método auxiliar (reutilização) ----------
    private static void Parametros(MySqlCommand cmd, Produto p)    // private: uso interno da classe
    {
        cmd.Parameters.AddWithValue("@nome", p.Nome);              // texto do nome
        cmd.Parameters.AddWithValue("@preco", p.Preco);            // decimal do preço
        cmd.Parameters.AddWithValue("@qtd", p.Quantidade);         // quantidade
        cmd.Parameters.AddWithValue("@cat", p.CategoriaId);        // id da categoria
    }
}

Programe o formulário · parte 1: carregar e exibir

Abra o código (F7). Dê clique duplo no formulário para criar o Load. No topo do arquivo, acrescente using MySqlConnector;.

// ----- campos da classe: vivem enquanto o formulário estiver aberto -----
private readonly ProdutoDAO produtoDAO = new();     // objeto que cuida dos produtos no banco
private readonly CategoriaDAO categoriaDAO = new(); // objeto que cuida das categorias no banco
private int idSelecionado = 0;                      // 0 = cadastrando novo; maior que 0 = editando esse id

private void FrmProdutos_Load(object sender, EventArgs e) // roda quando a tela abre
{
    if (!Conexao.Testar(out string mensagem))       // testa o banco; "out" devolve o texto do resultado
    {
        tslStatus.Text = mensagem;                  // mostra o problema na barra de status
        MessageBox.Show(mensagem, "Banco de dados", MessageBoxButtons.OK, MessageBoxIcon.Error); // e em uma janela
        Enabled = false;                            // desabilita a tela inteira: sem banco, nada funciona
        return;                                     // sai do método
    }

    Executar(CarregarCategorias);                   // preenche o ComboBox (dentro do tratamento de erros)
    Executar(CarregarGrade);                        // preenche a grade de produtos
    PrepararNovo();                                 // deixa a tela pronta para um novo cadastro
    tslStatus.Text = "Pronto.";                     // feedback inicial
}

// Executar recebe um "Action" (um método sem retorno) e o roda dentro de try/catch.
// Assim não repetimos try/catch em todo evento.
private void Executar(Action acao)
{
    try
    {
        acao();                                     // roda o método recebido
    }
    catch (MySqlException ex)                       // se o banco der erro...
    {
        string msg = ErroBanco.Traduzir(ex);        // ...converte para texto amigável
        tslStatus.Text = msg;                       // mostra na barra de status
        MessageBox.Show(msg, "Erro no banco de dados", MessageBoxButtons.OK, MessageBoxIcon.Error); // e avisa
    }
}

private void CarregarCategorias()
{
    cmbCategoria.DisplayMember = "Nome";            // propriedade que será MOSTRADA no ComboBox
    cmbCategoria.ValueMember = "Id";                // propriedade que será o VALOR de cada item
    cmbCategoria.DataSource = categoriaDAO.Listar(); // lista vinda do banco (defina Display/Value ANTES do DataSource)
}

private void CarregarGrade()
{
    dgvProdutos.DataSource = produtoDAO.Listar(txtBusca.Text.Trim()); // busca no banco e exibe na grade
    dgvProdutos.Columns["Id"].HeaderText = "Código";           // títulos mais amigáveis nas colunas
    dgvProdutos.Columns["Nome"].HeaderText = "Produto";
    dgvProdutos.Columns["Preco"].HeaderText = "Preço";
    dgvProdutos.Columns["Preco"].DefaultCellStyle.Format = "C2"; // C2 = moeda com 2 casas (R$ 9,50)
    dgvProdutos.Columns["Quantidade"].HeaderText = "Qtd.";
    dgvProdutos.Columns["CategoriaNome"].HeaderText = "Categoria";
    dgvProdutos.Columns["CategoriaId"].Visible = false;        // o usuário não precisa ver o id da categoria
    dgvProdutos.ClearSelection();                              // nenhuma linha selecionada ao carregar
}

Programe o formulário · parte 2: novo, validar e salvar

private void PrepararNovo()                         // volta a tela ao estado "cadastrar novo"
{
    idSelecionado = 0;                              // 0 = nenhum produto em edição
    txtNome.Clear();                                // limpa o nome
    nudPreco.Value = 0;                             // zera o preço
    nudQuantidade.Value = 0;                        // zera a quantidade
    if (cmbCategoria.Items.Count > 0)               // se existem categorias...
        cmbCategoria.SelectedIndex = 0;             // ...seleciona a primeira
    lblModo.Text = "Novo produto";                  // informa o modo atual ao usuário
    btnExcluir.Enabled = false;                     // não há o que excluir em um cadastro novo
    dgvProdutos.ClearSelection();                   // tira a seleção da grade
    txtNome.Focus();                                // cursor no primeiro campo
}

private bool Validar()                              // confere os dados ANTES de ir ao banco
{
    if (txtNome.Text.Trim().Length < 2)             // nome com pelo menos 2 letras
    {
        Avisar("Informe o nome do produto (mínimo de 2 letras).", txtNome);
        return false;                               // para na primeira falha
    }
    if (nudPreco.Value <= 0)                        // preço precisa ser positivo
    {
        Avisar("O preço deve ser maior que zero.", nudPreco);
        return false;
    }
    if (cmbCategoria.SelectedValue == null)         // nenhuma categoria escolhida
    {
        Avisar("Escolha uma categoria.", cmbCategoria);
        return false;
    }
    return true;                                    // tudo certo
}

private void Avisar(string mensagem, Control campo) // mostra o aviso e leva o cursor ao campo com problema
{
    tslStatus.Text = mensagem;                      // texto na barra de status
    campo.Focus();                                  // foco no campo
}

private void btnSalvar_Click(object sender, EventArgs e)
{
    if (!Validar()) return;                         // se inválido, não faz mais nada

    var produto = new Produto                       // monta o objeto com o que está na tela
    {
        Id = idSelecionado,                         // 0 = novo; outro valor = edição
        Nome = txtNome.Text.Trim(),                 // nome sem espaços nas pontas
        Preco = nudPreco.Value,                     // NumericUpDown.Value já é decimal
        Quantidade = (int)nudQuantidade.Value,      // converte decimal para int
        CategoriaId = (int)cmbCategoria.SelectedValue! // ValueMember = Id; "!" garante que não é nulo (já validamos)
    };

    Executar(() =>                                  // () => { } é uma função anônima passada para Executar
    {
        if (idSelecionado == 0)                     // novo produto
        {
            produtoDAO.Inserir(produto);            // INSERT
            tslStatus.Text = $"Produto \"{produto.Nome}\" cadastrado com sucesso!";
        }
        else                                        // produto existente
        {
            produtoDAO.Atualizar(produto);          // UPDATE
            tslStatus.Text = $"Produto \"{produto.Nome}\" atualizado com sucesso!";
        }
        CarregarGrade();                            // recarrega a lista para mostrar a mudança
        PrepararNovo();                             // limpa para o próximo cadastro
    });
}

Programe o formulário · parte 3: editar, excluir e buscar

private void dgvProdutos_CellClick(object sender, DataGridViewCellEventArgs e) // clique em uma célula da grade
{
    if (e.RowIndex < 0) return;                     // -1 = clicou no cabeçalho; ignora
    if (dgvProdutos.Rows[e.RowIndex].DataBoundItem is not Produto p) return; // pega o objeto Produto daquela linha

    idSelecionado = p.Id;                           // guarda qual produto está em edição
    txtNome.Text = p.Nome;                          // preenche os campos com os dados dele
    nudPreco.Value = p.Preco;
    nudQuantidade.Value = p.Quantidade;
    cmbCategoria.SelectedValue = p.CategoriaId;     // seleciona a categoria pelo valor (Id)
    lblModo.Text = $"Editando o produto #{p.Id}";   // avisa que está em modo de edição
    btnExcluir.Enabled = true;                      // agora existe um item que pode ser excluído
}

private void btnNovo_Click(object sender, EventArgs e) // botão Novo (e tecla Esc)
{
    PrepararNovo();                                 // reaproveita o método
    tslStatus.Text = "Pronto para um novo cadastro.";
}

private void btnExcluir_Click(object sender, EventArgs e)
{
    if (idSelecionado == 0) return;                 // segurança: nada selecionado

    var resposta = MessageBox.Show(                 // confirmação (heurística de controle e liberdade)
        $"Excluir o produto \"{txtNome.Text}\"? Esta ação não pode ser desfeita.",
        "Confirmar exclusão",
        MessageBoxButtons.YesNo,
        MessageBoxIcon.Warning,
        MessageBoxDefaultButton.Button2);           // "Não" é o botão padrão: caminho seguro
    if (resposta != DialogResult.Yes) return;       // se não confirmou, cancela

    Executar(() =>
    {
        produtoDAO.Excluir(idSelecionado);          // DELETE ... WHERE id = @id
        tslStatus.Text = "Produto excluído.";
        CarregarGrade();                            // atualiza a lista
        PrepararNovo();                             // limpa a tela
    });
}

private void txtBusca_TextChanged(object sender, EventArgs e) // dispara a cada letra digitada na busca
{
    Executar(CarregarGrade);                        // refaz a consulta com o novo texto (LIKE)
}

No designer, selecione cada controle e confira no ícone ⚡ (eventos) se estão ligados: btnSalvar_Click, btnNovo_Click, btnExcluir_Click, txtBusca_TextChanged e dgvProdutos_CellClick. Rode com F5 e faça: cadastrar, buscar, clicar na linha para editar, salvar a edição e excluir. Depois confira os dados no HeidiSQL (SELECT * FROM produtos;): eles estão realmente no banco.

Simule erros de propósito

Um sistema de qualidade é testado nas situações ruins também. Faça e anote o que acontece:

  • Cadastre dois produtos com o mesmo nome (erro 1062 traduzido).
  • No HeidiSQL, tente DELETE FROM categorias WHERE id = 1; (erro 1451: há produtos ligados).
  • Pare o MySQL no Laragon e clique em Salvar (mensagem de falha de conexão).
  • Digite ' OR '1'='1 na busca e veja que nada de estranho acontece (graças aos parâmetros).

Boas práticas de segurança (opcional)

Crie um usuário só para o sistema, com permissões limitadas, no HeidiSQL, e troque a connection string:

-- Cria o usuário "estoque_app" que só pode se conectar da própria máquina
CREATE USER 'estoque_app'@'localhost' IDENTIFIED BY 'Troque#Esta#Senha1';

-- Permite apenas ler e gravar DADOS no banco estoque (sem apagar tabelas nem mexer em outros bancos)
GRANT SELECT, INSERT, UPDATE, DELETE ON estoque.* TO 'estoque_app'@'localhost';

-- Aplica as permissões
FLUSH PRIVILEGES;

-- Depois, na classe Conexao, use:
-- "Server=localhost;Port=3306;Database=estoque;User ID=estoque_app;Password=Troque#Esta#Senha1;"
