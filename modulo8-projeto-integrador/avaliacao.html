3. Modelo de README.md

# Biblioteca Escolar

Sistema desktop (Windows Forms, C#) para controlar empréstimos de livros.

## Equipe
- Nome: papel
- Nome: papel

## Tecnologias
- C# / .NET 6+ · Windows Forms
- MySQL (Laragon) · MySqlConnector
- xUnit (testes) · Git/GitHub

## Como instalar e executar
1. Instale o Visual Studio (carga "Desenvolvimento para desktop com .NET") e o Laragon.
2. Inicie o MySQL no Laragon.
3. Execute o script `docs/banco.sql` no HeidiSQL.
4. Abra `Biblioteca.sln`, defina `Biblioteca.UI` como projeto de inicialização e pressione F5.
5. Se a senha do banco for diferente, ajuste `Conexao.cs`.

## Como rodar os testes
Menu Teste > Gerenciador de Testes > Executar Tudo.

## Funcionalidades
- Cadastro de livros e leitores
- Empréstimo e devolução com multa
- Listagem de empréstimos ativos

## Regras de negócio
(resuma RF03 a RF07 e RF10)

## Documentação
- Requisitos: docs/requisitos.md
- Banco de dados: docs/banco.sql
- Matriz de rastreabilidade: docs/rastreabilidade.md

5. Roteiro de apresentação (10 a 15 minutos)

  1. Problema e solução (1 min).
  2. Arquitetura: camadas, diagrama de classes, MER (2 min).
  3. Demonstração: emprestar, tentar violar uma regra, devolver com multa, banco desligado (4 min).
  4. Qualidade: testes unitários rodando, rastreabilidade, indicadores e Pareto (3 min).
  5. Git: histórico, branches e PRs (1 min).
  6. Lições aprendidas e melhorias futuras (1 min).
  7. Perguntas: qualquer integrante pode ser chamado a explicar qualquer parte.

9. Solução de problemas

SintomaCausa provávelO que fazer
Conflito de merge no GitDuas pessoas alteraram o mesmo trechoAbrir o arquivo, escolher o resultado correto (removendo <<<<<<<, =======, >>>>>>>), rodar os testes e fazer commit
“Referência circular” ao adicionar projetoCore referenciando Data ou UIRemover a referência: as dependências devem apontar para o Core
Erro de transação: “command not associated with transaction”Comando sem o parâmetro txPassar a transação ao construir o MySqlCommand
CHECK de disponiveis não impede valor inválidoVersão antiga do MySQL/MariaDB não aplica CHECKAtualizar o Laragon ou confiar nas regras do serviço e no AND disponiveis > 0
Grade mostra a coluna Id sem formataçãoProjeção anônima sem ajustesDefinir HeaderText/Visible das colunas
Testes passam local, mas falham na máquina do colegaDependência de data/hora do sistemaPassar a data por parâmetro (como em Emprestar(..., hoje))
Sistema não abre em outro computadorBanco não criado ou senha diferenteSeguir o README e conferir a string de conexão
