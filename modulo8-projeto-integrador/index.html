Projeto Integrador · Sistema completo em equipe

Chegou a hora de juntar tudo: requisitos, modelagem, programação orientada a objetos, banco de dados, interface, testes, documentação, versionamento e qualidade em um sistema Windows Forms desenvolvido em equipe. Este módulo traz um projeto de referência completo (Biblioteca Escolar) com código comentado e o passo a passo por sprints. Sua equipe pode desenvolver o mesmo sistema ou, com autorização do professor, um tema próprio seguindo o mesmo caminho.

Objetivos de aprendizagem

  • Levantar e especificar requisitos funcionais, não funcionais e regras de negócio.
  • Modelar o banco (MER) e as classes (herança, composição) e organizar a solução em camadas.
  • Implementar regras de negócio isoladas da interface e protegê-las com testes unitários.
  • Integrar o sistema ao MySQL do Laragon com parâmetros e transações.
  • Projetar telas usando princípios de UX/UI.
  • Trabalhar em equipe com Git (branches, commits rastreáveis e revisão).
  • Aplicar ferramentas da qualidade e registrar defeitos e indicadores.
  • Documentar, apresentar e demonstrar o sistema.

Foco do módulo

Núcleo obrigatório
  • Transformar requisitos em modelo, banco, classes e critérios de teste.
  • Trabalhar em camadas e manter o banco como fonte persistente de verdade.
  • Usar branches e Pull Requests para integrar trabalho da equipe.
  • Entregar aplicação executável com documentação, testes e evidências.
Aprofundamento
  • Aprimorar cobertura de testes, indicadores, tratamento de concorrência e processo de entrega.
  • Comparar decisões de arquitetura e registrar riscos e trade-offs.
✅ Critério de conclusãoO projeto está concluído quando outra pessoa consegue obter o repositório, configurar o ambiente seguindo o README, executar o sistema e verificar os requisitos por meio das evidências entregues.
🔗 Conexão com a trilhaEste módulo encerra a trilha. O passo seguinte é evoluir o projeto: novos requisitos, API/web, autenticação, relatórios ou implantação, conforme a próxima UC.

Pré-requisitos

  • Visual Studio (.NET 6 ou superior), Laragon com MySQL e Git instalados.
  • Conhecimento básico de Windows Forms, classes e SQL. Os módulos anteriores ajudam, mas o passo a passo aqui é completo.
