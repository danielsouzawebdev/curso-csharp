Qualidade do Código em C#

Código que funciona não basta: ele precisa ser legível, documentado, testado e rastreável. Neste módulo você aprende a escrever, revisar, depurar e provar a qualidade do que programa, usando os recursos do Visual Studio. O módulo é independente: exige apenas noções de classes e exceções em C#.

Objetivos de aprendizagem

  • Aplicar padrões de nomenclatura e formatação de código.
  • Documentar código com comentários XML (///) e comentários explicativos.
  • Refatorar para eliminar repetição e melhorar a clareza (reutilização de código).
  • Medir e otimizar trechos de código com critério.
  • Depurar usando pontos de interrupção, janelas de inspeção e pilha de chamadas.
  • Escrever e executar testes unitários com xUnit no Gerenciador de Testes.
  • Identificar erros comparando o comportamento do programa com os requisitos.
  • Manter rastreabilidade entre requisito, código, teste e commit.

Foco do módulo

Núcleo obrigatório
  • Aplicar convenções de nomes e formatação de forma consistente.
  • Usar o depurador para investigar um defeito a partir de evidências.
  • Refatorar sem alterar o comportamento esperado.
  • Criar testes unitários com xUnit e relacionar requisito, código e teste.
Aprofundamento
  • TDD como uma estratégia possível de desenvolvimento — não como obrigação para todo problema.
  • Medições simples para comparar alternativas antes e depois de otimizações.
✅ Critério de conclusãoVocê concluiu o módulo quando consegue reproduzir um defeito, criar ou executar um teste que o evidencia, corrigir a causa e registrar a mudança no Git.
🔗 Conexão com a trilhaNo Módulo 7, o foco sobe do código individual para a qualidade do processo e do produto como um todo.

Conhecimentos do plano de curso atendidos

Formatação · Documentação de código · Reutilização de código · Técnicas de otimização · Depuração · Rastreabilidade · Teste unitário · Identificação de erros conforme o requisito · Repositórios e controle de versão (uso básico).

Pré-requisitos

  • Visual Studio com Desenvolvimento para desktop com .NET (.NET 6 ou superior).
  • Criar classes, métodos, propriedades e lançar exceções.
  • Git instalado (o Visual Studio já inclui suporte).
