Prática guiada · Encontrando e corrigindo defeitos

🧭 Como executar esta práticaDigite o código, execute a cada etapa e compare o comportamento com o resultado descrito. Se houver erro, leia a mensagem antes de alterar o código e use o depurador quando indicado.

Cenário: um colega entregou a classe Conta de um sistema bancário dizendo que “está tudo funcionando”. Seu trabalho: provar o que está certo e errado usando testes, encontrar as causas com o depurador, corrigir, documentar, refatorar e manter a rastreabilidade. Faça na ordem e digite os códigos lendo os comentários.

💡 Códigos para .NET 6 ou superior. Não corrija nada antes da etapa 8: primeiro entenda o problema.

Leia os requisitos

Os requisitos são a referência da verdade. O código só está certo se cumprir o que está escrito aqui. Leia com atenção cada palavra (repare em “no mínimo”, “maior que zero” e “menor ou igual”).

IDRequisito
RF01A conta é criada com titular obrigatório de no mínimo 3 caracteres (sem contar espaços nas pontas) e saldo inicial zero.
RF02O depósito só é aceito para valor maior que zero e aumenta o saldo.
RF03O saque só é aceito para valor maior que zero e menor ou igual ao saldo somado ao limite; caso contrário, é recusado com erro.
RF04Conta corrente tem limite de R$ 500,00; conta poupança não tem limite.
RF05Transferência debita a origem e credita o destino. Se a origem não puder sacar, nenhuma conta é alterada.
RF06O extrato lista as operações em ordem cronológica, com tipo, valor e saldo após cada operação.

Crie o código recebido

Em Banco.Core, adicione a classe Conta.cs com o conteúdo abaixo (é o código do colega). Não procure defeitos ainda: leia os comentários para entender o que cada linha faz.

namespace Banco.Core;                                   // namespace da biblioteca: agrupa as classes

public enum TipoConta { Corrente, Poupanca }            // enum: lista fixa de tipos de conta

public class Movimentacao                               // uma linha do extrato
{
    public DateTime Data { get; init; }                 // quando ocorreu (init: só pode ser definido na criação)
    public string Tipo { get; init; } = "";             // "Depósito" ou "Saque"
    public decimal Valor { get; init; }                 // valor da operação
    public decimal SaldoApos { get; init; }             // saldo da conta depois da operação
}

public class Conta
{
    public string Titular { get; }                      // só get: definido no construtor e nunca mais muda
    public TipoConta Tipo { get; }                      // tipo da conta
    public decimal Saldo { get; private set; }          // private set: só a própria classe altera o saldo

    // Propriedade calculada: conta corrente tem R$ 500 de limite; poupança, nenhum.
    public decimal Limite => Tipo == TipoConta.Corrente ? 500 : 0;

    private readonly List<Movimentacao> movimentacoes = new(); // lista interna do extrato
    public IReadOnlyList<Movimentacao> Movimentacoes => movimentacoes; // visão somente leitura para quem está fora

    public Conta(string titular, TipoConta tipo)        // construtor: roda ao criar a conta
    {
        if (string.IsNullOrWhiteSpace(titular) || titular.Trim().Length <= 3) // rejeita nome vazio ou curto
            throw new ArgumentException("Titular inválido.");                 // interrompe a criação
        Titular = titular.Trim();                       // guarda o nome sem espaços nas pontas
        Tipo = tipo;                                    // guarda o tipo
        Saldo = 0;                                      // conta nova começa zerada
    }

    public void Depositar(decimal valor)                // coloca dinheiro na conta
    {
        if (valor < 0)                                  // rejeita valores negativos
            throw new ArgumentException("Valor inválido.");
        Registrar("Depósito", valor);                   // anota no extrato
        Saldo += valor;                                 // soma ao saldo
    }

    public void Sacar(decimal valor)                    // tira dinheiro da conta
    {
        if (valor <= 0)                                 // rejeita zero e negativos
            throw new ArgumentException("Valor inválido.");
        if (valor >= Saldo + Limite)                    // rejeita se passar do disponível
            throw new InvalidOperationException("Saldo insuficiente.");
        Registrar("Saque", valor);                      // anota no extrato
        Saldo -= valor;                                 // subtrai do saldo
    }

    public void Transferir(Conta destino, decimal valor) // passa dinheiro para outra conta
    {
        destino.Depositar(valor);                       // coloca o valor na conta de destino
        Sacar(valor);                                   // tira o valor desta conta
    }

    private void Registrar(string tipo, decimal valor)  // cria uma linha no extrato
    {
        movimentacoes.Add(new Movimentacao              // adiciona ao final da lista (ordem cronológica)
        {
            Data = DateTime.Now,                        // data e hora atuais
            Tipo = tipo,                                // tipo recebido
            Valor = valor,                              // valor recebido
            SaldoApos = Saldo                           // saldo no momento do registro
        });
    }
}

Escreva os testes a partir dos requisitos

Em Banco.Tests, crie ContaTests.cs. Cada teste verifica uma regra de um requisito, seguindo o padrão AAA e o nome Metodo_Cenario_Resultado.

using Banco.Core;                                       // acesso às classes que serão testadas
using Xunit;                                            // biblioteca de testes

namespace Banco.Tests;

public class ContaTests
{
    // ==================== RF01: criação da conta ====================
    [Fact]                                              // [Fact] marca um teste simples
    public void Criar_TitularComTresLetras_Aceita()
    {
        var conta = new Conta("Ana", TipoConta.Corrente); // ARRANGE+ACT: cria a conta com nome de 3 letras (mínimo permitido)
        Assert.Equal("Ana", conta.Titular);             // ASSERT: o titular foi guardado
        Assert.Equal(0m, conta.Saldo);                  // 0m = decimal zero: conta nova começa sem saldo
    }

    [Theory]                                            // [Theory] repete o teste para cada [InlineData]
    [InlineData("")]                                    // nome vazio
    [InlineData("   ")]                                 // só espaços
    [InlineData("Al")]                                  // 2 letras: abaixo do mínimo
    public void Criar_TitularInvalido_LancaExcecao(string titular)
    {
        Assert.Throws<ArgumentException>(               // espera que a exceção ocorra...
            () => new Conta(titular, TipoConta.Corrente)); // ...ao executar esta função
    }

    // ==================== RF02: depósito ====================
    [Fact]
    public void Depositar_ValorPositivo_AumentaSaldo()
    {
        var conta = new Conta("Ana Souza", TipoConta.Corrente); // ARRANGE
        conta.Depositar(100);                           // ACT
        Assert.Equal(100m, conta.Saldo);                // ASSERT
    }

    [Theory]
    [InlineData(0)]                                     // zero não é um depósito válido
    [InlineData(-10)]                                   // negativo também não
    public void Depositar_ValorZeroOuNegativo_LancaExcecao(int valor)
    {
        var conta = new Conta("Ana Souza", TipoConta.Corrente);
        Assert.Throws<ArgumentException>(() => conta.Depositar(valor));
    }

    // ==================== RF03 e RF04: saque e limite ====================
    [Fact]
    public void Sacar_DentroDoSaldo_ReduzSaldo()
    {
        var conta = new Conta("Ana Souza", TipoConta.Poupanca);
        conta.Depositar(100);
        conta.Sacar(40);
        Assert.Equal(60m, conta.Saldo);                 // 100 - 40
    }

    [Fact]
    public void Sacar_ExatamenteSaldoMaisLimite_Permite()
    {
        var conta = new Conta("Ana Souza", TipoConta.Corrente); // corrente: limite de 500
        conta.Depositar(100);                           // disponível = 100 + 500 = 600
        conta.Sacar(600);                               // sacar exatamente o disponível deve ser permitido
        Assert.Equal(-500m, conta.Saldo);               // saldo fica negativo, usando o cheque especial
    }

    [Fact]
    public void Sacar_AcimaDoDisponivel_LancaExcecao()
    {
        var conta = new Conta("Ana Souza", TipoConta.Corrente);
        conta.Depositar(100);                           // disponível = 600
        Assert.Throws<InvalidOperationException>(() => conta.Sacar(601)); // 1 centavo acima do disponível não pode
    }

    [Fact]
    public void Poupanca_SacarTodoSaldo_Permite()
    {
        var conta = new Conta("Ana Souza", TipoConta.Poupanca); // poupança: sem limite
        conta.Depositar(100);
        conta.Sacar(100);                               // sacar exatamente o saldo deve ser permitido
        Assert.Equal(0m, conta.Saldo);
    }

    [Fact]
    public void Poupanca_NaoUsaLimite()
    {
        var conta = new Conta("Ana Souza", TipoConta.Poupanca);
        conta.Depositar(100);
        Assert.Throws<InvalidOperationException>(() => conta.Sacar(101)); // acima do saldo, sem limite
    }

    // ==================== RF05: transferência ====================
    [Fact]
    public void Transferir_ComSaldo_DebitaOrigemECreditaDestino()
    {
        var origem = new Conta("Ana Souza", TipoConta.Poupanca);
        var destino = new Conta("Bruno Lima", TipoConta.Corrente);
        origem.Depositar(200);
        origem.Transferir(destino, 50);
        Assert.Equal(150m, origem.Saldo);               // 200 - 50
        Assert.Equal(50m, destino.Saldo);               // 0 + 50
    }

    [Fact]
    public void Transferir_SaldoInsuficiente_NaoAlteraNenhumaConta()
    {
        var origem = new Conta("Ana Souza", TipoConta.Poupanca);
        var destino = new Conta("Bruno Lima", TipoConta.Corrente);
        origem.Depositar(50);                           // origem só tem 50 e não tem limite
        Assert.Throws<InvalidOperationException>(() => origem.Transferir(destino, 100)); // falha esperada
        Assert.Equal(50m, origem.Saldo);                // origem intacta
        Assert.Equal(0m, destino.Saldo);                // destino NÃO pode ter recebido nada
    }

    // ==================== RF06: extrato ====================
    [Fact]
    public void Extrato_AposDeposito_RegistraSaldoApos()
    {
        var conta = new Conta("Ana Souza", TipoConta.Corrente);
        conta.Depositar(100);
        Assert.Equal(100m, conta.Movimentacoes[0].SaldoApos); // o saldo registrado é o de DEPOIS da operação
    }

    [Fact]
    public void Extrato_VariasOperacoes_MantemOrdemCronologica()
    {
        var conta = new Conta("Ana Souza", TipoConta.Corrente);
        conta.Depositar(100);
        conta.Sacar(30);
        Assert.Equal("Depósito", conta.Movimentacoes[0].Tipo); // primeira operação feita = primeira do extrato
        Assert.Equal("Saque", conta.Movimentacoes[1].Tipo);    // segunda operação = segunda do extrato
        Assert.Equal(70m, conta.Movimentacoes[1].SaldoApos);   // 100 - 30
    }
}

Depure o primeiro defeito (passo a passo)

Vamos depurar Sacar_ExatamenteSaldoMaisLimite_Permite aplicando o método da Teoria:

  1. Reproduzir: o teste já faz isso, e ele falha com InvalidOperationException: Saldo insuficiente.
  2. Ponto de interrupção: abra Conta.cs e pressione F9 na primeira linha do método Sacar.
  3. Depurar o teste: no Gerenciador de Testes, clique direito no teste → Depurar. A execução para no ponto.
  4. Observar: na janela Locais, veja valor = 600. Em Inspeção, digite Saldo (100), Limite (500) e Saldo + Limite (600).
  5. Avançar: pressione F10 até a linha do segundo if. Observe que o programa entra no throw.
  6. Hipótese: “600 não deveria ser recusado, pois é exatamente o disponível”.
  7. Verificar na janela Imediata (Depurar → Janelas → Imediata): digite valor >= Saldo + Limite (resultado true) e depois valor > Saldo + Limite (resultado false). Está confirmado: o operador >= recusa o valor exato.

Veja também a Pilha de Chamadas (Depurar → Janelas): ela mostra que o teste chamou Sacar.

Agora você: repita o processo para os outros testes vermelhos. Registre cada um no diário:

Quando todos os testes estiverem verdes, compare com a versão final abaixo. Ela traz as correções, a documentação XML (///), constantes nomeadas e o método extraído ValidarValorPositivo. Só abra depois de tentar sozinho.

Ver os 5 defeitos e a versão final documentada
#RequisitoDefeito
1RF01Length <= 3 recusava nomes de 3 letras; o correto é < 3.
2RF02valor < 0 aceitava depósito de zero; o correto é <= 0.
3RF03/RF04valor >= Saldo + Limite recusava o valor exato; o correto é >.

namespace Banco.Core;

/// <summary>Tipos de conta aceitos pelo sistema.</summary>
public enum TipoConta
{
    /// <summary>Conta corrente: possui limite de cheque especial.</summary>
    Corrente,
    /// <summary>Conta poupança: não possui limite.</summary>
    Poupanca
}

/// <summary>Registro de uma operação realizada em uma conta (linha do extrato).</summary>
public class Movimentacao
{
    /// <summary>Data e hora em que a operação ocorreu.</summary>
    public DateTime Data { get; init; }
    /// <summary>Descrição do tipo de operação (por exemplo, "Depósito" ou "Saque").</summary>
    public string Tipo { get; init; } = "";
    /// <summary>Valor movimentado, sempre positivo.</summary>
    public decimal Valor { get; init; }
    /// <summary>Saldo da conta imediatamente após a operação.</summary>
    public decimal SaldoApos { get; init; }
}

/// <summary>Representa uma conta bancária com saldo, limite e extrato.</summary>
/// <remarks>Implementa os requisitos RF01 a RF06 do documento de requisitos.</remarks>
public class Conta
{
    private const decimal LimiteContaCorrente = 500m;       // constante nomeada: o número 500 deixa de ser "mágico" (RF04)
    private const int TamanhoMinimoTitular = 3;             // regra do RF01 em um só lugar

    /// <summary>Nome do titular da conta, sem espaços nas extremidades.</summary>
    public string Titular { get; }

    /// <summary>Tipo da conta (corrente ou poupança).</summary>
    public TipoConta Tipo { get; }

    /// <summary>Saldo atual. Pode ser negativo em contas correntes (uso do limite).</summary>
    public decimal Saldo { get; private set; }

    /// <summary>Limite de cheque especial: R$ 500 na corrente e zero na poupança (RF04).</summary>
    public decimal Limite => Tipo == TipoConta.Corrente ? LimiteContaCorrente : 0;

    private readonly List<Movimentacao> movimentacoes = new();
    /// <summary>Extrato em ordem cronológica (RF06).</summary>
    public IReadOnlyList<Movimentacao> Movimentacoes => movimentacoes;

    /// <summary>Cria uma conta com saldo zero.</summary>
    /// <param name="titular">Nome do titular, com no mínimo 3 caracteres.</param>
    /// <param name="tipo">Tipo da conta.</param>
    /// <exception cref="ArgumentException">Titular vazio ou com menos de 3 caracteres (RF01).</exception>
    public Conta(string titular, TipoConta tipo)
    {
        if (string.IsNullOrWhiteSpace(titular) || titular.Trim().Length < TamanhoMinimoTitular) // < : 3 letras é válido
            throw new ArgumentException("O titular deve ter no mínimo 3 caracteres.", nameof(titular)); // nameof evita texto fixo
        Titular = titular.Trim();
        Tipo = tipo;
        Saldo = 0;
    }

    /// <summary>Deposita um valor na conta (RF02).</summary>
    /// <param name="valor">Valor maior que zero.</param>
    /// <exception cref="ArgumentException">Valor menor ou igual a zero.</exception>
    public void Depositar(decimal valor)
    {
        ValidarValorPositivo(valor);                    // regra reaproveitada (DRY)
        Saldo += valor;                                 // PRIMEIRO altera o saldo...
        Registrar("Depósito", valor);                   // ...DEPOIS registra, para o extrato mostrar o saldo correto (RF06)
    }

    /// <summary>Saca um valor da conta, respeitando o limite (RF03 e RF04).</summary>
    /// <param name="valor">Valor maior que zero e até o saldo somado ao limite.</param>
    /// <exception cref="ArgumentException">Valor menor ou igual a zero.</exception>
    /// <exception cref="InvalidOperationException">Valor acima do disponível.</exception>
    public void Sacar(decimal valor)
    {
        ValidarValorPositivo(valor);
        if (valor > Saldo + Limite)                     // > : sacar exatamente o disponível é permitido
            throw new InvalidOperationException("Saldo insuficiente.");
        Saldo -= valor;
        Registrar("Saque", valor);
    }

    /// <summary>Transfere um valor desta conta para outra (RF05).</summary>
    /// <param name="destino">Conta que receberá o valor.</param>
    /// <param name="valor">Valor a transferir.</param>
    /// <remarks>Se o saque falhar, nenhuma das contas é alterada.</remarks>
    public void Transferir(Conta destino, decimal valor)
    {
        ArgumentNullException.ThrowIfNull(destino);     // falha clara se esquecerem o destino
        Sacar(valor);                                   // PRIMEIRO debita: se falhar, a exceção impede o crédito
        destino.Depositar(valor);                       // só credita depois que o débito deu certo
    }

    private static void ValidarValorPositivo(decimal valor) // método extraído: antes a regra estava repetida
    {
        if (valor <= 0)
            throw new ArgumentException("O valor deve ser maior que zero.", nameof(valor));
    }

    private void Registrar(string tipo, decimal valor)
    {
        movimentacoes.Add(new Movimentacao
        {
            Data = DateTime.Now,
            Tipo = tipo,
            Valor = valor,
            SaldoApos = Saldo
        });
    }
}

Refatore com as ferramentas do Visual Studio

Pratique em uma cópia do código e rode os testes após cada passo:

  1. Renomear (F2): renomeie o campo movimentacoes para _movimentacoes; observe que todas as referências mudam sozinhas.
  2. Extrair método (Ctrl+R, M): selecione as linhas do if (valor <= 0) throw ... e extraia para ValidarValorPositivo.
  3. Introduzir constante (Ctrl+.): selecione o 500 e escolha “Introduzir constante”.
  4. Formatar (Ctrl+K, Ctrl+D): deixe o arquivo todo com indentação padrão.
  5. Remover usos desnecessários (Ctrl+.): apague using não utilizados.

Se um teste ficar vermelho após um passo, desfaça (Ctrl+Z) e investigue: a refatoração mudou o comportamento.

Meça e otimize

No projeto Banco.Console, substitua o conteúdo de Program.cs pelo código abaixo. Rode em modo Release (selecione “Release” na barra superior e use Ctrl+F5) e anote os tempos. Os valores variam de computador para computador; o importante é a diferença entre as técnicas.

using System.Diagnostics;                                // traz o Stopwatch (cronômetro)
using System.Text;                                       // traz o StringBuilder

const int N = 20000;                                     // quantidade de repetições do teste

// ---------- TESTE 1: montar um texto grande ----------
var cronometro = Stopwatch.StartNew();                   // cria e já liga o cronômetro
string extratoLento = "";                                // texto começa vazio
for (int i = 0; i < N; i++)                              // repete N vezes
{
    extratoLento += $"Movimentação {i}\n";               // += cria uma NOVA string copiando a anterior a cada volta
}
cronometro.Stop();                                       // para o cronômetro
Console.WriteLine($"Concatenação com +: {cronometro.ElapsedMilliseconds} ms"); // ElapsedMilliseconds: tempo decorrido

cronometro.Restart();                                    // zera e liga de novo
var sb = new StringBuilder();                            // StringBuilder acumula o texto em um buffer interno
for (int i = 0; i < N; i++)
{
    sb.AppendLine($"Movimentação {i}");                  // acrescenta sem recriar o texto inteiro
}
string extratoRapido = sb.ToString();                    // só no final gera a string completa
cronometro.Stop();
Console.WriteLine($"StringBuilder:       {cronometro.ElapsedMilliseconds} ms");

// ---------- TESTE 2: buscar um item ----------
var lista = new List<(int Numero, string Nome)>();       // lista de pares (número, nome)
var dicionario = new Dictionary<int, string>();          // dicionário: chave = número, valor = nome
for (int i = 0; i < 50000; i++)                          // 50 mil cadastros
{
    lista.Add((i, "Cliente " + i));                      // adiciona nas duas estruturas
    dicionario[i] = "Cliente " + i;
}

cronometro.Restart();
for (int k = 0; k < 1000; k++)                           // faz 1000 buscas
{
    var achado = lista.Find(x => x.Numero == 49999);     // List: confere item por item até achar (busca linear)
}
cronometro.Stop();
Console.WriteLine($"Busca em List:       {cronometro.ElapsedMilliseconds} ms");

cronometro.Restart();
for (int k = 0; k < 1000; k++)
{
    var achado = dicionario[49999];                      // Dictionary: vai direto ao item pela chave (tabela hash)
}
cronometro.Stop();
